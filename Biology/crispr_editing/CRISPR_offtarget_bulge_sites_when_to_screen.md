# Bulge 型脱靶 —— 什么时候必须筛，什么时候筛了反而更差

- **创建日期**：2026-11-26
- **本文由来**：展开 `Utilities/Biology/crispr_editing/CRISPR_editing_primer.md` **§5** 的 bulge 那一行
  （原文仅一句"`seqkit locate` 做不到，需 Cas-OFFinder"）。原行保留不动作为速查；本文是它的完整版。
- **定位**：**跨项目通用参考**，不绑定任何客户或项目。
  凡是要在 WGS / 靶向测序里回答"脱靶筛查够不够全"，先读本文。
- **一句话用法**：**bulge 不是"要不要做得更全"的问题，是"做了会不会把检出力做没"的问题。**
  候选数膨胀会抬高多重检验背景；在纯 mismatch 位点零阳性的项目里，补 bulge 轮的
  **期望收益为负**。该做的是把它写成有层次的局限，而不是补一轮更弱的筛查。

## 1. 决策表：拿到一个项目，先查这一张

| 情形 | 筛 bulge？ | 理由 |
| :--- | :---: | :---: |
| **纯 mismatch 臂已有阳性脱靶位点** | **要** | 已证明这把 gRNA 在体系里确实会脱靶 ⇒ 相邻的 bulge 位点先验概率同步抬高，且有可比的阳性标尺 |
| **纯 mismatch 臂零阳性（含 0–1 mm 位点也零）** | **不要** | 预期效率更低的位点在更严的校正阈值下更不可能过 —— 见 §4 |
| **客户的科学问题就是"脱靶完备性"**（安全性评估、申报资料、审稿人质询） | **要** | 此时"做过 bulge 筛查"本身是交付内容，不只是为了找到位点 |
| **有无偏臂**（全基因组 SV/indel 的 treated-vs-control 私有变异） | **不要**（但要在报告里说清） | 无偏臂不使用任何序列相似性模型 ⇒ bulge 型脱靶若造成结构变异仍会被捕获，见 §6 |
| **只有候选驱动臂，没有无偏臂** | **要** | 此时 mismatch-only 是**真正的绝对盲区**，没有任何旁路覆盖 |
| **gRNA 长度非 20 nt / 截短型（tru-gRNA）** | **要** | 【景·待核】截短 spacer 的错配容忍谱与标准 20 nt 不同，继承标准口径的候选表不安全 |

**读这张表的方式**：先看项目有没有**无偏臂**（第 4/5 行）。有无偏臂 ⇒ bulge 是"候选臂盲区"，
可以不筛但必须在报告里降级表述；没有无偏臂 ⇒ bulge 是绝对盲区，不筛就不能声称筛查完整。
第 1/2 行再按 mismatch 臂的实测结果定；第 3 行凌驾前面所有行。

## 2. 机制：bulge 位点存在，但系统性更弱

**什么是 bulge**【景】：gRNA 侧或 DNA 侧多出 1 个（偶尔 2 个）碱基，使两条链无法等长配对，
必须环出（loop out）一个碱基才能继续互补。

| 类型 | 多出的碱基在哪 | 别名 |
| :--- | :---: | :---: |
| **DNA bulge** | DNA 靶侧多 1 nt（gRNA 比靶区短） | 插入型 |
| **RNA bulge** | gRNA 侧多 1 nt（gRNA 比靶区长） | 缺失型 |

**为什么更弱**【景】：形成 bulge 要多付一份构象/能量代价，Cas9 的 R-loop 才能继续延伸。
所以在**同等 mismatch 数**下，带 bulge 的位点切割效率系统性低于纯 mismatch 位点。

**实际占比**【景·待核】：在 GUIDE-seq / CHANGE-seq 这类无偏方法的验证位点集里，
只能用 bulge 模型解释的位点属少数（印象中 **< 10%**），且绝大多数是
**1-nt bulge 配 ≤2–3 mismatch** —— 即在相似性排序上**紧邻高分 mismatch 位点**的那一类，
而不是散布在序列空间的远处。
**⚠ 进对外文字前必须查原始文献核实比例**（Lin et al. 2014 *NAR* 是 bulge 容忍的原始证据；
占比要引无偏筛查方法的综述，不要引我这句）。

**这个"紧邻"的性质有操作含义**【推】：bulge 位点不是独立的新风险区，而是已枚举高分区的
**边缘加宽**。所以在高分区（0–2 mm）全部零阳性的项目里，加宽边缘的信息增量很小。

## 3. 为什么 mismatch-only 枚举抓不到 —— 这是算法层面的，不是参数层面的

| 方法 | 比对模型 | 能否出 bulge 位点 |
| :--- | :---: | :---: |
| `seqkit locate -m` / numpy 全量扫描 / 自写 Hamming 距离 | **等长比对**，逐位比字符 | **不能**（原理上） |
| `bwa` / `bowtie` 比对 spacer | 带 gap 的局部比对 | 理论上能，但短序列 + 多命中下**灵敏度与可控性都不够**，不是正规做法 |
| **Cas-OFFinder** ≥ 2.4 | **gap-aware**，显式枚举 DNA/RNA bulge 到指定长度 | **能**（领域标准工具） |
| CRISPRitz | 同上，另带变异感知（可叠加个体 VCF） | 能 |

**关键点**【推】：mismatch-only 的工具**不是"参数没开对"，是模型里没有 gap 这个维度**。
调 `-m`、放宽 mismatch 上限、加 PAM 变体，一个都不会变出 bulge 位点。
所以"我把 mismatch 放宽到 5–6 个，相当于覆盖了 bulge"是错的 ——
放宽 mismatch 只在等长空间里扩大半径，和 gap 空间是正交的两件事。

## 4. 补做的真实代价 —— 本文最重要的一节

### 4.1 候选数膨胀

【推】1-nt DNA + RNA bulge、mismatch 上限 ≤3，全基因组候选数通常比纯 mismatch ≤4 mm
**膨胀 1–2 个数量级**（具体倍数取决于 spacer 的 GC 与重复性，必须实测，不要照抄倍数）。
每个新候选位点仍要走一遍完整的 read-level 证据流程（深度 / indel / clip / MAPQ / secondary /
supplementary 分层统计），算力随之线性放大。

### 4.2 ⚠ 检出力可能**下降**，不是上升

这是最反直觉、也最容易被"做得更全总是更好"直觉盖掉的一点【推】：

1. 逐位点统计检验的 p 值有**离散下限**，由样本数决定（n=10 的置换/二项检验下限约 **0.0083**）。
2. 候选数从 1.6k 涨到几万，FDR / Bonferroni 校正后的通行阈值同步收紧。
3. 当校正阈值降到离散下限以下时，**没有任何位点能过阈 —— 连 on-target 都过不了**。

⇒ **"加一轮 bulge 筛查"可能把原本能过阈的真阳性一起废掉。**
这不是统计洁癖，是设计约束：**候选空间大小必须和样本数匹配**。

**【推】对策（真要做 bulge 轮时）**：
- **不要把 bulge 候选并进主表一起校正**。两张表、两套校正，各自报各自的发现。
- 或者**只筛"紧邻区"**：对已枚举的高分 mismatch 位点做 ±1-nt bulge 的局部扩展，
  候选数只涨几倍而非几十倍，与 §2 "bulge 位点是高分区边缘加宽"的性质一致。
- 先算**检出力**再开跑：给定 n、给定候选数，校正后的阈值是多少、离散下限是多少，
  **能不能过**。算这个的成本是分钟级，比跑完一轮再发现全不显著便宜几个数量级。

## 6. 不筛 bulge 时，报告该怎么写

**错的写法**（把它写成绝对盲区，防守性最差）：

> Sites that the guide could reach by looping out a base (a "bulge") are not covered by this screen.

**问题**【推】：这句读起来像"这类脱靶我们完全不知道"。客户或审稿人下一问必然是
"那你怎么知道没有"，而此时项目其实**有**旁路证据，只是报告没写。

**对的写法（三层结构）**【推】：

| 层 | 要写的内容 |
| :--- | :---: |
| ① 限定盲区范围 | 候选位点枚举基于 mismatch 模型，bulge 位点不在**该臂**覆盖内 |
| ② 指出旁路覆盖 | 全基因组私有 SV/indel 臂**不使用任何序列相似性模型**，bulge 型脱靶若在克隆中造成结构变异仍会被该臂捕获 |
| ③ 给该臂的实测结果 | 该臂在 N 个 treated 克隆中的命中情况（给数字，不给形容词） |

⇒ 盲区从"绝对盲区"降级为"**候选臂盲区 + 无偏臂部分覆盖**"。
**这不是话术，是事实的分层**：两条臂的证据模型确实不同，原来的写法把它们混为一谈了。

**⚠ 边界**：②只有在项目**真有**无偏臂时才能写。没有无偏臂还这么写 = 把没做过的检查
写成带结论意味的句子。

## 7. 本机实证：P46 为什么不补 bulge 轮

【测】项目 `projects_2026Q4/46_park_wgs`（RPE1 双切，10 样本：3 control + 7 treated）。

| 证据臂 | 口径 | 实测结果 | 产物 |
| :--- | :---: | :---: | :---: |
| mismatch 候选臂 | 3 个 spacer 版本 × 全基因组 ≤4 mm，NGG 主表 + NAG 次表，**1,587 候选位点** | on-target 3 行 **p = 0.0083**（离散下限）；**1,580 个位点 p = 1**；另 4 个位点 p = 0.18–0.50（均不显著）⇒ **候选空间内零个可信脱靶** | `analysis/stage2b_offtarget_evidence_20261123_v2/tables/offtarget_evidence_n10.tsv`（1,588 行含表头） |
| 无偏 private-SV 臂 | **不使用序列相似性模型** | treated 克隆私有 SV **4–28 个/样本**；命中脱靶候选区的只有 Sample_4 的 **2** 个（chr19 inv） | `analysis/stage5_prep_20261125/tables/private_sv_per_sample.tsv` |

**判定**【推】：命中 §1 决策表第 2 行（mismatch 臂零阳性，含 0–1 mm 位点）**与**第 4 行（有无偏臂）
⇒ **不补 bulge 轮**。且 n=10 的 p 值离散下限已是 0.0083，候选数再膨胀一个数量级，
校正后 **on-target 自己都过不了阈**（§4.2 的教科书式例子）。

**仍待办**：该项目报告 1126 版的 Limitation 2 用的是 §6 的"错的写法"，
应按 §6 三层结构加强。报告处于内部审阅阶段，**未擅自修改**，已记作待办。
