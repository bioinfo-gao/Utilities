# 递送方式 —— 决定要不要额外筛查外源序列

- **创建日期**：2026-11-25
- **本文由来**：展开 `Utilities/Bioinfo/crispr_editing/CRISPR_editing_primer.md` **§6**
  （原文仅一张 4 行表 + 两个陷阱）。原节保留不动，作为速查；本文是它的完整版。
- **定位**：**跨项目通用参考**，不绑定任何客户或项目。
  凡是要在 WGS / 靶向测序里回答"基因组里有没有多出来的外源序列"，先读本文。
- **一句话用法**：**递送方式决定了"要不要查、查什么、拿什么当阴性对照"**。
  这三件事在建参考序列之前就必须定下来，事后补不回来 —— 漏建的参考等于系统性盲区，
  而盲区在结果里长得和"干净"一模一样。

## 1. 决策表：拿到一个项目，先查这一张

| 递送方式 | 进细胞的是什么 | 会不会在基因组里留下 DNA | **必须筛查什么** | 阴性对照（设计自带的） |
| :--- | :--- | :---: | :--- | :--- |
| **RNP**（Cas9 蛋白 + gRNA） | 蛋白 + RNA | **不会**（无 DNA 分子） | 不需要筛外源序列 | — |
| **mRNA**（Cas9 mRNA + gRNA） | RNA | **基本不会**（见 §2.3 的例外） | 不需要；若客户坚持，查 Cas9 CDS 即可 | Cas9 CDS 应为 0 |
| **瞬转质粒** | 环状 DNA | **可能**（随机整合 + 切点捕获） | **Cas9 CDS + 骨架（AmpR / ori）+ 靶点切口处的质粒片段** | 骨架与 CDS 拷贝数应同为 0 |
| **逆转录病毒**（MMLV 系） | 整合前病毒 cDNA | **一定会**（稳定整合） | **整合位点 + 两 LTR 之间的全部元件；骨架应为 0** | **骨架（ori/AmpR）= 0**，它们在 LTR 之外 |
| **慢病毒**（HIV-1 系） | 同上 | **一定会** | 同上；偏好基因体内，位点数常更多 | 同上 |
| **AAV** | 单链 DNA（ITR 夹着） | **多为游离附加体，低频整合** | **ITR 序列 + 靶点切口处的 ITR 捕获** | 全基因组均匀覆盖 vs 位点性覆盖，见 §3.5 |
| **转座子**（PiggyBac / Sleeping Beauty） | 质粒 + 转座酶 | **一定会**，且拷贝数常 > 1 | **转座子两端 + 插入位点的特征性重复**（TTAA / TA） | 转座酶质粒本身**不应**整合 |
| **HDR 供体**（质粒 / ssODN） | DNA | **可能**（串联体 + 骨架插入靶点） | **供体骨架 + 靶点处的供体串联** | 骨架应为 0；见 §3.7 |

**读这张表的方式**：先看第 3 列。
"不会"⇒ 省掉整个载体筛查环节；"可能"或"一定会"⇒ **第 4 列的每一项都必须在建参考时就纳入**。

## 2. 为什么递送方式决定筛查范围 —— 三条机制

> 理解这三条，就不用背表了：**外源 DNA 要进基因组，只有这三条路。**

### 2.1 路径一：病毒自带的整合机器【景】

逆转录病毒与慢病毒的生命周期本来就包含"整合"这一步：
病毒 RNA 逆转录成 cDNA ⇒ 整合酶把**两个 LTR 之间的序列**插进宿主基因组。

**三条可直接用于判读的推论**：
1. **只有 LTR 之间的序列会进去** ⇒ 质粒骨架（ori、AmpR）**原理上不该出现在基因组里**。
   ⇒ **这是设计自带的阴性对照，不花钱、不用额外实验，必须用。**
2. 插入位点有偏好（MMLV 偏启动子/增强子附近，HIV-1 偏基因体内）【景】
   ⇒ 整合位点落在基因里**不等于**有功能后果，也不等于"脱靶"。
3. MMLV 需要细胞分裂才能整合，HIV-1 不需要【景】
   ⇒ 这解释了为什么逆转录病毒常用于可分裂的细胞系。

### 2.2 路径二：DSB 修复把游离 DNA 当成修补材料吞进去【景】

这是**所有 DNA 形式递送**（质粒、AAV、供体）共有的风险，也是最容易被忽略的一条：

细胞核里同时存在 ① 一个新鲜的 Cas9 切口、② 一堆游离的外源 DNA 片段
⇒ NHEJ 在接断口时**可能把外源片段连进去**。

**后果有两种，必须分开查**：

| 形态 | 发生在哪 | 怎么查 |
| :--- | :--- | :--- |
| **随机整合** | 基因组任何自发断裂处 | 全基因组找 基因组↔载体 junction |
| **切点捕获（on-target capture）** | **就在你自己设计的靶点上** | **查靶点读段里有没有比不上基因组的插入序列** |

**⚠ 第二种最阴**：它发生在你最关注的那个位置，而且
**如果参考里没有该载体序列，这段插入只会表现为"一段 soft-clip"或"比对不上的读段"**
⇒ 看起来像测序噪声，而真相是靶点被插进了一段质粒。
⇒ **凡用 DNA 形式递送，靶点分析必须额外做一轮"clip 序列回贴载体"**，不能只看 indel。

### 2.3 路径三：罕见的逆转录介导插入【景·待核】

RNA（mRNA 递送）本身没有整合途径。理论上内源 LINE-1 的逆转录酶可以把 mRNA 逆转录成 cDNA
再插入，但这属极罕见事件。

⇒ **实践口径**：mRNA 递送**按"不留 DNA"处理**，不单独建参考。
**原 primer §6 表里"mRNA / 瞬转质粒"合并成一行、写"可能随机整合"，
这里把两者拆开** —— 风险几乎完全来自质粒那一半，合写会让人对 mRNA 过度筛查。

## 3. 逐方式展开

### 3.1 RNP（蛋白 + gRNA 复合物）

| 项 | 内容 |
| :--- | :--- |
| 进细胞的 | Cas9 蛋白与 gRNA 预组装的复合物，电穿孔 / nucleofection 导入 |
| 基因组留痕 | **无**。没有任何 DNA 分子进入 |
| 暴露窗口 | 短（蛋白数小时内降解）【景】⇒ **脱靶通常少于持续表达的方式** |
| 筛查 | **不需要**。报告里"未检出 Cas9 整合"是**预期结果，不是发现** |

**⚠ 两个常见误解**：
1. "RNP 没有载体，所以不用做载体筛查" —— **错，前提是这一轮只用了 RNP。**
   细胞系本身可能在**更早的实验里**就带了整合的构建体（报告器、选择标记、Cas9-EGFP）。
   ⇒ **要查的是"这株细胞的基因组里有什么"，不是"这一轮加了什么"。**
2. "Cas9 不进基因组，所以 Cas9 序列不用建参考" —— **建了更好**：
   把它纳入作探查，**有则报、无则构成阴性对照**，成本几乎为零。

### 3.2 瞬转质粒

| 项 | 内容 |
| :--- | :--- |
| 基因组留痕 | **可能**：随机整合 + §2.2 的切点捕获 |
| 必查 | **Cas9 CDS、骨架（AmpR / ori）、整个质粒序列（用于 clip 回贴）** |
| 关键陷阱 | **"0 覆盖"有三种含义，见 §5.1** |

**时间维度是这一类独有的问题**【推】：瞬转质粒在不分裂稀释与降解下**会逐渐消失**。
如果 gDNA 是在转染后很久采的（例如单克隆扩增成系之后），
**检不到质粒既可能是"从未整合"，也可能是"整合没发生、游离的那些早被稀释掉了"**。
⇒ 报告只能写"**未检出整合**"，**不能写"未发生整合"**。

### 3.3 逆转录病毒（MMLV / MSCV / pLPC 等骨架）

| 项 | 内容 |
| :--- | :--- |
| 基因组留痕 | **一定有**，稳定遗传给所有子代 |
| 必查 | 整合 junction 位点；LTR 之间每个元件的拷贝数；**骨架必须为 0** |
| 预期拷贝数 | 低 MOI 下常为 1–2 份【景】 |

**为什么研究者愿意付这个代价**【推】+【景】：活细胞成像需要**连续数小时到数天、跨细胞分裂**地
稳定表达。瞬转的报告器会衰减、不同细胞表达量差异大，成像做到一半信号就没了。
⇒ **稳定整合不是图方便，是长时程可比性的前提。**

**代价是随机插入位点** ⇒ 必然产出一批与编辑无关的 junction。
**判读规则（设计直接给出，不是事后解释）**：
**凡"所有克隆共有的 junction"一律判为共同转导亲本携带，与本轮编辑无关。**

### 3.4 慢病毒

与 3.3 同，两点差别【景】：
① 可在不分裂的细胞中整合；② 插入偏好基因体内部，位点数常更多。
⇒ 分析侧没有本质差别，但**"落在基因里"的比例天然更高，不要据此推断功能影响**。

### 3.5 AAV

| 项 | 内容 |
| :--- | :--- |
| 基因组留痕 | **以游离附加体为主，低频整合**【景】 |
| 必查 | **ITR 序列**（整合与切点捕获的特征标记）、载体全长 |
| 独有形态 | 基因组内常形成**串联体（concatemer）**【景·待核】 |

**怎么区分"游离"与"整合"**【推】——这是个很干净的判据：

| | 游离附加体 | 整合 |
| :--- | :--- | :--- |
| 覆盖形态 | **全长均匀覆盖，骨架/ITR 都在** | 常为**部分**序列，边界由整合机制决定 |
| 基因组↔载体 junction | **没有** | **有，且断点在多条读段间固定** |
| 随克隆传代 | 逐渐稀释 | 稳定 |

⇒ **"有没有固定断点的 junction"是区分二者的核心证据，覆盖深度本身不够。**

### 3.6 转座子（PiggyBac / Sleeping Beauty）

| 项 | 内容 |
| :--- | :--- |
| 基因组留痕 | **一定有**，且**拷贝数常 > 1**（可到数份至数十份）【景·待核】 |
| 必查 | 转座子两端序列；**插入位点的特征性靶位点重复**（PiggyBac: `TTAA`；SB: `TA`）【景】 |
| 阴性对照 | **转座酶质粒本身不应整合** ⇒ 它的拷贝数应为 0 |

**特征性重复是这一类的"签名"**：插入位点两侧会出现复制出来的 TTAA / TA
⇒ **这是可以写成硬断言的判据**：找到的插入位点若没有该重复，先怀疑是假阳性。

### 3.7 HDR 供体（质粒 / ssODN）

**要查的不是"有没有"，而是"是不是干净地只进去了一份"**【推】：

| 要查的形态 | 为什么 |
| :--- | :--- |
| **供体串联体** | 多份供体首尾相接插进靶点，PCR/凝胶可能仍显示"正确大小"的一条带 |
| **骨架随供体一起插入靶点** | §2.2 的切点捕获，质粒供体的高发形态 |
| **半边 HDR（单侧同源臂重组）** | 一侧正确、另一侧是 NHEJ 接头 ⇒ 常规扩增引物可能两侧都在供体内，检不出 |

⇒ **凡做 HDR，靶点的"正确"必须用跨越整个插入区（含两侧基因组锚点）的证据判，
不能只看插入片段本身在不在。**

## 4. 筛查流程（通用 SOP）

> 顺序不能换：第 1 步没做对，后面全部白做。

| 步 | 做什么 | 为什么是这个顺序 |
| :---: | :--- | :--- |
| **1** | **把每个构建体的完整序列（含骨架）建成额外 contig** | 参考里没有的序列，比对器永远不会告诉你它存在 —— 它只会产出 soft-clip |
| **2** | **把载体按读长瓦片化回贴宿主基因组，标出可映射区并屏蔽** | 载体里的宿主源序列（人 cDNA 融合报告器等）会造成**双向**假象，见 §5.2 |
| **3** | 取候选读段：unmapped / mate-unmapped / soft-clip ≥ 20 bp | 全量回贴浪费算力；这三类覆盖了所有可能来自载体的读段 |
| **4** | 候选读段回贴载体 ⇒ 算**各元件**覆盖与拷贝数（不是整载体均值，见 §5.4） | — |
| **5** | **基因组端 clip（≥25 bp, MAPQ≥20）回贴载体** ⇒ 求整合 junction | 方向不能反，见 §5.3 |
| **6** | **靶点专门再做一轮 clip 回贴载体** | §2.2 的切点捕获就发生在靶点上，全基因组扫描容易把它当成普通 indel |
| **7** | 跑阴性 + 阳性双向定标 | 见下 |

**第 7 步的双向定标（没有它，前 6 步的结果不可信）**：

| 方向 | 用什么当定标 | 预期 |
| :--- | :--- | :--- |
| **阳性** | 已知一定存在的那个元件（报告器的荧光蛋白、已知的共有 junction） | **必须检出**，否则流程本身失灵 |
| **阴性** | 骨架（AmpR / ori）、或已知未使用的载体 | **必须为 0**，否则存在假阳性来源 |

## 5. 六个静默陷阱（不报错、输出看起来正常）

### 5.1 ⚠ "0 覆盖"有三种完全不同的含义

| 看到 0 / NA | 可能是 | 怎么区分 |
| :--- | :--- | :--- |
| 真的没有这段序列 | — | 需要阳性定标证明流程能检出 |
| **被屏蔽掉了** | §4 第 2 步的 mask 把该段 `unmasked_bp` 归零 | **看 mask 文件**，不要看汇总表 |
| 曾经有、被稀释掉了 | 瞬转质粒 + 长期培养（§3.2） | 设计上无法区分 ⇒ 只能写"未检出" |

**【测】实证**：某项目的报告器中 53BP1-FFR 段在汇总表里是 `NA`，看起来像没测到；
查逐碱基深度实为 **8–14×**，是屏蔽把它剔除了。
⇒ **正确表述是"该段读段无法归属、按设计排除"，不是"未检出"。**
两种写法在报告里会被读成完全相反的意思。

### 5.2 ⚠ 载体里的宿主源序列 —— 双向假象

载体常含宿主 cDNA（融合报告器、人源启动子/增强子、宿主来源的 polyA）。这造成**两个方向**的错误：

| 方向 | 现象 | 后果 |
| :--- | :--- | :--- |
| 漏（假阴性） | 这些读段**能比上宿主基因组** ⇒ 不进 unmapped 池 | 只用未比对读段筛查，该区段得 0 覆盖，像"没有这个载体" |
| 冒（假阳性） | 内源基因的读段会被回贴到载体上 | **把内源基因位置误判成"载体整合位点"** |

**【测】实证**：某项目第一版未屏蔽，把 3 个"载体整合位点"**全部**判在该 cDNA 对应的内源基因上，全是同源假象。
**必做**：§4 第 2 步的瓦片化 + 屏蔽。

### 5.3 ⚠ 载体是环状、参考是线性 ⇒ clip 回贴方向不能反

跨质粒首尾接口的读段必被 clip，**那些 clip 是载体自己的序列**，不是基因组序列。
⇒ 求整合 junction 必须 **基因组端 clip → 回贴载体**；
反方向（载体端 clip → 回贴基因组）测到的是**线性化假接口**，会批量产出假位点。

### 5.4 ⚠ 整载体平均覆盖度没有生物学含义

**【测】实证**：某项目一个报告器质粒，实测
**表达盒（CMV–荧光蛋白）约 1 拷贝、骨架（ori/AmpR）精确为 0**，
而"整载体平均"是 **0.27–0.32** —— 这个数既不是 1 也不是 0，**是两者平均出来的，不对应任何实体**。

⇒ **拷贝数一律按元件分报**：表达盒、各 LTR、选择标记、骨架各自一行。
整载体均值只能用于**样本间相对比较**（且须先归一化），不可作为"载体拷贝数"引用。

### 5.5 ⚠ 共有元件的低值反映可映射性，不反映含量

多个载体共有的元件（LTR、抗性基因、通用骨架、常见启动子）会被 MAPQ 过滤压低。
⇒ **拷贝数估计只用"该载体唯一"的元件**（Cas9、EGFP、mCherry 这类）。

### 5.6 ⚠ 分子与分母必须同口径

`拷贝数 ≈ 2 × 元件平均深度 ÷ 全基因组平均深度`（二倍体中 1 份 ⇒ 1.00）。

**两个口径必须一致**，否则会系统性偏差：

| 项 | 常见错法 | 正确做法 |
| :--- | :--- | :--- |
| 分子（载体侧） | 用 `samtools depth`，**配对重叠区每个 mate 各计一次** | — |
| 分母（基因组侧） | 用 mosdepth 默认，**做了 mate-overlap 校正** | **改用未做 overlap 校正的去重深度** |

⇒ 短 insert 文库（insert ≈ 读长）下这个差异可达**近两倍**，足以把 1 拷贝报成 2 拷贝。

**另一条**：样本间比较前须按**候选读段总数**归一 —— 否则重复率高的样本会系统性偏高。

## 6. 必须向客户问清的四件事（问不到就不能替他填）

> 判据只有一条：**这项信息决定了我方要建什么参考**。参考建错是事后补不回来的。

| # | 问什么 | 不问清会怎样 |
| :---: | :--- | :--- |
| 1 | **递送方式**（RNP / mRNA / 质粒 / 病毒 / 转座子 / AAV），以及**本轮**与**更早**分别用了什么 | 直接决定第 1 列的整张表；"本轮是 RNP"不排除细胞系早就带着整合构建体 |
| 2 | **每个构建体的完整序列，含骨架** | 只给 CDS ⇒ 无法做骨架阴性对照，也无法用 clip 回贴找 junction |
| 3 | **选择/富集方式**（药物筛选？荧光分选？） | 决定哪些元件"必须功能完整地存在"，是拷贝数结果的旁证 |
| 4 | **采样时间点相对递送的间隔** | §3.2：决定"未检出"能不能推向"未发生" |

**⚠ 属于我方决定、不要问客户的**：参考基因组版本、比对器、caller、阈值、瓦片长度、
