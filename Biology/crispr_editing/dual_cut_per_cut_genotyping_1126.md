## 1. 三段话说完（结论在最前）

**第一段 —— 判定对象是「分子」，而观测单位比它小。**
二倍体细胞每个位点有两条等位基因，**等位基因是一条连续的 DNA 分子**。
双切设计要判的是「**每一条**等位基因在**两个**切点各处于什么状态」。
但本批数据的读段只有 150 bp，而两个切点相距 **202 bp**【测】
⇒ **在未发生缺失的那条等位上，一条读段永远不可能同时看到两个切点。**

**第二段 —— 所以「某条等位在两切点都完整」这件事，在这份数据里是推断、不是观测。**
推断必须这样搭：先**分切点**统计「有多少条分子在这个切点是完整的 / 带 indel 的」，
再把两个切点的结论**联合**起来。
**跨切点求和会把「位置」这个标签抹掉**，而位置标签正是唯一携带相位（phase）信息的变量。
抹掉之后，「同一条等位在两切点都完整」与「两批不同的分子各自只在一个切点完整」
在数字上**完全同形**，无法区分。

**第三段 —— 代价是一个静默的错误基因型。**
P46 的 Sample_5 实测：CUT1 处干净跨越读段 **0** 条、带 indel 跨越读段 **12** 条；
CUT2 处干净 **13** 条、带 indel **0** 条【测】。
逐切点读 ⇒ 第二条等位**在 CUT1 带一个 8 bp 缺失、在 CUT2 完整** ⇒ **两条等位都被编辑过**。
求和读 ⇒ 干净 13 条 vs 带 indel 12 条 ⇒ 「存在一条干净等位」⇒ **「单等位 Δ202，另一等位 WT」**。
**后者不报错、数字自洽、而且能通过流程里的外部定标断言**（§7 给出实证）
⇒ 这是一个只能靠设计避免、无法靠事后检查发现的错误。

## 2. 先把三个量和它们各自管什么分清

靶点是 `chr3`，两个切点坐标常数 `CUT1 = 195,542,947`、`CUT2 = 195,543,149`，
约定是「切口位于该坐标紧邻的 3′ 侧」；被删区间 `195,542,948–195,543,149` 共 **202 bp**【测】
（`scripts/11_stage1_ontarget.py:40,167`）。

脚本并列三类证据，**三者互相独立、各自只能回答一个问题**：

| 证据 | 怎么定义的 | 只回答这个问题 | 对什么**盲** |
| :--- | :---: | :---: | :---: |
| **接头读段** `J`（junction read） | soft-clip ≥ 20 bp，且 clip 段序列与**对侧**下游参考一致度 ≥ 0.90 | **存不存在 Δ202 等位？有多少条分子支持？** | 对「另一条等位是什么」完全盲 |
| **跨越读段**，分 `clean` / `indel`，**按切点分别计** | 起点 ≤ cut−15 且终点 ≥ cut+15 且 maxclip < 20；再按切点 ±10 bp 内有无 I/D 分两类 | **非 Δ202 的那条等位，在这个切点是完整的还是带 indel 的？** | 单个切点的统计对**另一个**切点盲 |
| **缺失区归一化深度** `d_norm` | 缺失区间平均深度 ÷ 同口径局部基线深度；另出 ±50 kb 侧翼轮廓 `f_left`/`f_right` | **202 bp 这段丢了几个拷贝？丢失是否只限于这 202 bp？** | 对 8 bp 量级的 indel 几乎完全盲 |

**三个量少任何一个，都会有两种结局被混为一谈**（`11_stage1_ontarget.py:9-17` 的 docstring
把这三态写死了）：

| 结局 | `J` | `d_norm` | 侧翼 | 逐切点 `clean`/`indel` |
| :--- | :---: | :---: | :---: | :---: |
| 两条等位各自 Δ202 | 高 | ≈ 0 | **正常 ≈ 1.0** | 两切点 clean 均 ≈ 0 |
| Δ202 + 另一等位更大范围丢失 | 高 | ≈ 0 | **也塌陷 < 0.75** | 两切点 clean 均 ≈ 0 |
| Δ202 + 另一等位切点小 indel | 半 | **≈ 0.5** | 正常 | **某一切点 clean ≈ 0 而 indel ≈ 半** |
| 单等位 Δ202 + 另一等位 WT | 半 | **≈ 0.5** | 正常 | **两切点 clean 均 > 0** |

- 前两行在**缺失区内的深度上完全一样**，只能靠**侧翼轮廓**分开。
- 后两行在**深度上完全一样**（`d_norm` 都 ≈ 0.5），**只能靠把跨越读段拆成 clean/indel 且分切点统计**分开。
  ⇒ **这就是「逐切点」存在的唯一理由。**

## 3. 核心：为什么「求和」在逻辑上就不成立

### 3.1 判定单位是等位基因，测量单位是读段，两者不是一回事

要判的命题是关于**一条分子**的：

> **命题 A**：存在一条等位基因，它在 CUT1 **和** CUT2 **都**保持参考序列的连续性。

能观测到的是关于**一条读段**的：

> **观测 b**：这条读段在 CUT1 处连续且无 indel。
> **观测 c**：那条读段在 CUT2 处连续且无 indel。

**命题 A 要求 b 与 c 发生在同一条分子上。**
把 b 类读段数与 c 类读段数相加，得到的是「总共有多少次'某个切点完整'的观测」，
这是把**位置**这个维度**边缘化（marginalize）掉**之后的量。
而命题 A 恰恰是一个关于「两个位置的联合状态」的命题
⇒ **求和后的量在数学上不再包含回答命题 A 所需的信息**，无论怎么设阈值都救不回来。

这和「选择单位不能与测量单位混用」是同一类错误
（参见 `feedback_zero_result_prove_denominator` 记下的那条判据）：
**判定单位（等位基因 / 分子）比测量单位（读段）大，中间那层聚合必须显式地做，不能用求和代替。**

### 3.2 一个不对称性：缺失等位上两切点**是**共观测的，完整等位上**不是**

这是整件事最容易被忽略、也最关键的一点：

| 等位状态 | 两个切点之间的实际距离 | 一条 150 bp 读段能否同时覆盖两个切点 |
| :--- | :---: | :---: |
| **已发生 Δ202** | **0 bp**（中间 202 bp 已被删除，两断端直接相连） | **能** —— 这正是「接头读段」的定义 |
| **未发生 Δ202**（WT 或仅带小 indel） | **仍是 202 bp** | **不能** |

所以：
- **缺失等位的相位是被直接观测到的**。一条接头读段本身就证明「同一条分子的左断端与右断端相连」，
  不需要任何联合推断 —— 缺失把两个切点**拉进了同一个观测窗口**。
- **完整等位的相位是观测不到的**。两个切点仍相距 202 bp，超出读段跨度
  ⇒ 必须逐切点统计后再联合。

**⇒ 「逐切点」不是保守，而是对「只有一侧的相位可被直接观测」这个不对称事实的正确应对。**

### 3.3 片段（read pair）层面也救不了 —— 实测而非估算

有人会想：mate 不就能跨过去吗？本批 insert size 均值 **144.6–186.6 bp**【测】
（Sample_5 为 **162.1 ± 45.9 bp**【测】），而要带 15 bp 锚定地跨过两个切点需要 ≥ **232 bp**。

实测窗口 `chr3:195,541,000–195,545,000` 内、起点 ≤ CUT1−15 且终点 ≥ CUT2+15 的**片段数**：

| 样本 | 可跨两切点的片段数 |
| :--- | :---: |
| Sample_5 | **1** |
| Sample_7 | **0** |
| Ctr_1 | **3** |

（口径：`samtools view -F 0x904 -f 0x2`，用 `POS` 与 `TLEN` 推片段区间。
同窗口内 `TLEN ≥ 232 bp` 的片段占 9.64%，但其中位置恰好能骑住两个切点的只剩上表这几条。）

⇒ **0–3 条片段撑不起任何基因型陈述**（真杂合在 ~25× 下预期 10–16 条量级）。
片段层面的相位信息在这份数据里**实测为不可用**，不是「没去用」。

> **⚠ 这不是建议换平台。** 它是一句**局限陈述**：相位在本数据的观测跨度之外，
> 所以判定必须按逐切点联合来搭。对客户只写局限本身，不接「建议改做长读长」
> （见 `SHARED_AGENT_RULES` 的禁令）。

## 4. Sample_5 实例：两种读法逐步推演

### 4.1 实测数字【测】

来源 `analysis/stage1_ontarget_20261123/tables/ontarget_summary.tsv`：

| 量 | CUT1 | CUT2 |
| :--- | :---: | :---: |
| 干净跨越读段 `clean` | **0** | **13** |
| 带 indel 跨越读段 `indel` | **12** | **0** |
| 该切点的缺失等位比例 `J/(J+clean)` | **1.000** | **0.500** |

全样本层面：`J = 13`、`d_norm = 0.566`、侧翼 `f_left = 1.018` / `f_right = 1.108`、
`f_del = 0.434`、supplementary 32 条、secondary 0 条。

切点 indel 谱（`indels_near_cutsites.tsv`）：**21 条 alignment record，全部是 CUT1 处的 `D 8`**
（位置 195,542,946 / 195,542,947），去重后 **13 个 read name**，其中 **12 个**同时满足跨越读段的
锚定条件，即上表的 `cross_indel_CUT1 = 12`【测】（差的那 1 个未通过锚定或 clip 条件【推】）。
**indel 尺寸完全一致（全为 8 bp）** ⇒ 与「单一克隆性事件」一致【推】，
而非多种 NHEJ 产物混杂。

### 4.2 逐切点读法（正确）

1. `J = 13` 且 `d_norm = 0.566` ⇒ **有一条 Δ202 等位，另一条不是 Δ202**（深度丢了约一半）。
2. 侧翼 1.018 / 1.108 正常 ⇒ 丢失**只限于那 202 bp**，排除「另一等位更大范围丢失」。
3. 问「另一条等位在每个切点是什么状态」：
   - **CUT1**：干净 0 条、带 indel 12 条 ⇒ 这条等位在 CUT1 处**带 8 bp 缺失**。
     干净读段为 **0** 是强陈述 —— 不是「少」，是「一条都没有」。
   - **CUT2**：干净 13 条、带 indel 0 条 ⇒ 这条等位在 CUT2 处**完整**。
4. 联合 ⇒ **一条 Δ202 + 一条「CUT1 处 8 bp 缺失、CUT2 完整」** ⇒ **两条等位都经 Cas9 切割并由 NHEJ 修复**。

流程判定：`双等位编辑：一条 Δ202 + 一条切点 indel(CUT1)`，
`allele2_state = 切点小 indel @ CUT1`，`clonality = 与杂合一致`【测】。

### 4.3 求和读法（错误）—— 错在哪一步

把两切点合并：

| 合并后的量 | 算式 | 值 |
| :--- | :---: | :---: |
| 干净跨越读段合计 | 0 + 13 | **13** |
| 带 indel 跨越读段合计 | 12 + 0 | **12** |
| 合并后的缺失等位比例 | 13 ÷ (13 + 13) | **0.500** |

于是会这样推：

> 「有 13 条干净跨越读段 ⇒ 存在一条两切点都完整的等位；
> 缺失等位比例 0.50、`d_norm` 0.566、侧翼正常 ⇒ 教科书式的杂合。」
> ⇒ **判定「单等位 Δ202（另一等位 WT）」**

**三个数字彼此自洽、全部指向同一个错误答案。**
（代入脚本的分支：合并后 `indel(12) >= clean(13)` 不成立 ⇒ `indel_cuts` 为空
⇒ 落到 `clean > 0` 分支 ⇒ `allele2_state = "WT（两切点均有干净跨越读段）"`。
注意这个分支名本身就暴露了前提：它要求**两切点都有**干净读段，
而求和之后已经无法检验「两切点都有」这件事。）

**错在第一步**：那 13 条干净读段**全部位于 CUT2**，它们干净是因为第二条等位在 CUT2 处本就完整；
那 12 条带 indel 的读段**全部位于 CUT1**，来自**同一条**第二等位。
两批读段描述的是**同一条分子的两个不同位置**，求和却把它们当成了**两类分子**的计数。

**最直接的旗标**：逐切点的缺失等位比例 **1.000（CUT1）vs 0.500（CUT2）**。
同一条等位上两个切点若状态相同，这两个比例应当接近；
**差到 2 倍就说明两切点状态不同** —— 而求和恰好把这个旗标平均成了无害的 0.500。

### 4.4 对照：真正的「两切点状态相同」长什么样

| 样本 | `J` | clean CUT1 / CUT2 | `d_norm` | 侧翼 | 判定 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Ctr_1 | 0 | 25 / 22 | 1.025 | 1.04 / 1.08 | WT（阴性**有覆盖支撑**） |
| Sample_1 | 6 | 15 / 13 | — | 正常 | 单等位 Δ202；af 0.286 / 0.316 |
| **Sample_5** | 13 | **0 / 13** | 0.566 | 正常 | **双等位编辑（Δ202 + CUT1 indel）** |
| Sample_7 | 22 | **0 / 0** | 0.004 | 1.08 / 1.08 | 双等位 Δ202 |

- **Ctr_1 / Sample_1 的两个 clean 数接近**（25≈22、15≈13）⇒ 两切点状态一致，求和与逐切点同结论。
- **Sample_7 两个 clean 都是 0 且 `d_norm` ≈ 0** ⇒ 双等位 Δ202，同样不需要靠逐切点救。
- **只有 Sample_5 这种「两切点不同态」才会被求和毁掉。**
  ⇒ 所以这个坑**在 7/8 个样本上都看不出来**，只在特定基因型上发作。
  **一条在多数样本上无害的规则违反，正是最容易被保留下来的那种。**

## 5. 生物学后果：两个判定的含义完全不同

| | 逐切点判定 | 求和判定 |
| :--- | :---: | :---: |
| 分子结论 | 一条 Δ202 + 一条 CUT1 处 8 bp 缺失 | 一条 Δ202 + 一条未被改动的 WT |
| **被编辑的等位数** | **2 条** | **1 条** |
| 细胞里还有没有一条未受扰动的参考序列等位 | **没有** | **有** |
| 对「编辑效率 / 切割是否双等位发生」的推论 | 两刀在两条等位上都切到了 | 只有一条等位被切 |
| 对下游组间比较的影响 | 该样本按双等位编辑计入 | 该样本按杂合计入 ⇒ **低估编辑组与对照组的差异** |

**凝胶分辨不出这个区别**【景】：8 bp 的长度差在为 202 bp 差异设计的凝胶上通常并不分开
⇒ 带 8 bp 缺失的等位在凝胶上表现为「长带」，与真 WT 同位置。
客户对 Sample_5 的先验是「双等位」【客】，这是**功能层面**的判断；
**分子本质（双 Δ202 还是 Δ202 + 小 indel）必须由测序给出，报告要把两者写清。**

> **⚠ 一个本文没有做的检查**：这个 8 bp 缺失**是否造成功能失活**，取决于它相对
> PPP1R2 起始密码子与读码框的位置。**本文未做这个核对，因此不下任何功能结论。**
> 要查就查 `gencode.v45.annotation.gtf` 里 PPP1R2 的 CDS 起点与 `chr3:195,542,946-195,542,954`
> 的关系（参考 `/Work_bio/references/Homo_sapiens/GRCh38/human_gencode_v45/`）。
> 可说的只有：**两条等位都经过了切割与 NHEJ 修复**。

## 5A. 附：克隆纯度（clonality）怎么判 —— 与相位正交的第二个轴

**为什么放在这篇里**：§4.4 的对照表里 Sample_1/2 被标成「亚克隆」、Sample_3/4 标成「与杂合一致」，
用的是**同一批数字的另一个读法**。相位（§3–§4）问「每条等位是什么」，
克隆纯度问「**所有细胞是不是同一个基因型**」—— 两个问题正交，必须分开判。

### 5A.1 判定全部由一个量、一个阈值决定

`11_stage1_ontarget.py:330-338`【测】：

```
f_del = 1 − d_norm          # 缺失掉的染色体拷贝占比
f_del >= 0.75               → 双等位/纯合样
0.35 <= f_del < 0.75        → 与杂合一致
f_del <  0.35               → 亚克隆（Δ202 占比 << 50%，克隆不纯）
```

**生物学前提只有一句**：
**纯克隆 + 单等位缺失 ⇒ 每个细胞都带该缺失，只是两条等位里的一条 ⇒ Δ202 占比必然 ≈ 0.50。**
（这正是 `CRISPR_editing_primer.md` §4 那条禁令的来源：
「不是全部拷贝都带缺失」这种说法把**等位基因层面**与**细胞层面**混为一谈。）

⇒ **占比显著低于 0.50，在单等位已确认的前提下只能来自「群体里混有未编辑细胞」。**

### 5A.2 实测数字与落点【测】

来源 `ontarget_summary.tsv`。`af` = 接头读段法 `J/(J+clean)`，分切点给出：

| 样本 | `J` | `d_norm` | **`f_del` = 1−`d_norm`** | `af` CUT1 / CUT2 | 落点 | 判定 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| Sample_1 | 6 | 0.707 | **0.293** | 0.286 / 0.316 | **< 0.35** | 亚克隆 |
| Sample_2 | 4 | 0.677 | **0.323** | 0.333 / 0.235 | **< 0.35** | 亚克隆 |
| Sample_3 | 20 | 0.533 | **0.467** | 0.541 / 0.606 | 0.35–0.75 | 与杂合一致 |
| Sample_4 | 8 | 0.402 | **0.598** | 0.667 / 0.500 | 0.35–0.75 | 与杂合一致 |

**两类样本的分离很干净**：S1/S2 的两法估计都落在 **0.24–0.33**，S3/S4 都落在 **0.47–0.61**，
两组之间没有重叠。

### 5A.3 「两法互证」的论据力到底有多强 —— 分别量化

记录里写「两个检出效率完全不同的估计量给出同一个数 ⇒ 不是方法偏差」，这个推理成立，
但**两法单独拿出来都不够硬**，必须说清：

**读段法（二项检验，H0 = 0.50，双侧精确检验）**【测】：

| 样本 | CUT1 `k/n` | CUT1 `p` | CUT2 `k/n` | CUT2 `p` |
| :--- | :---: | :---: | :---: | :---: |
| Sample_1 | 6/21 | **0.078** | 6/19 | **0.167** |
| Sample_2 | 4/12 | **0.388** | 4/17 | **0.049** |
| Sample_3 | 20/37 | 0.743 | 20/33 | 0.296 |
| Sample_4 | 8/12 | 0.388 | 8/16 | 1.000 |

⇒ **没有一个切点能单独把 S1/S2 判在 0.05 以下并站稳**；Sample_2 的 CUT1（p = 0.388）
单看完全不显著。**读段数太少**（n = 12–21）。

**深度法的噪声，用三个对照自己定标**【测】——
对照的真值恒为 `d_norm = 1.000`，实测却是 **1.025 / 1.093 / 1.202**
（均值 1.107、样本 sd 0.089、极差 0.177）⇒ 这个估计量在本深度下单次误差约 **±0.09–0.18**。
以该 sd 为标尺：

| 样本 | `d_norm` 偏离 0.50 | 折合对照 sd |
| :--- | :---: | :---: |
| Sample_1 | +0.207 | **+2.3 σ** |
| Sample_2 | +0.177 | **+2.0 σ** |
| Sample_3 | +0.033 | +0.4 σ |
| Sample_4 | −0.098 | −1.1 σ |

⇒ 深度法给 S1/S2 的是 **2 σ 量级**的提示，不是铁证，而且这个 σ 本身只由 **n = 3** 估出来，很弱。

**⇒ 结论的真正支点是两法的独立性**：深度法不经过 junction 比对、读段法不经过深度归一化，
两者**没有共同的失败模式**，却在 S1/S2 同向给出 0.24–0.33、在 S3/S4 同向给出 0.47–0.61。
**这是「不是方法偏差」的合法论据；而「单个方法已达统计显著」不是，不要那样写。**

### 5A.4 ⚠ 一个必须排除的替代解释：局部三体也给 ≈ 0.33

**若该位点是 3 个拷贝而缺失只发生在 1 个拷贝上，占比恰好 1/3 = 0.333**【景】——
与 Sample_2 的 0.323、Sample_1 的 0.293 都很接近。
编辑实验常用的近二倍体细胞系普遍带有已知的非整倍体区段【景】
⇒ **这个解释必须显式排除，不能默认两拷贝。**

**已排除**【测】：侧翼 ±50 kb 的 mosdepth 归一化深度（与 `genome_mean` **同口径**）为

| 样本 | `flank_left_norm` | `flank_right_norm` |
| :--- | :---: | :---: |
| Sample_1 | 1.051 | 1.067 |
| Sample_2 | 1.034 | 1.139 |
| Ctr_1 / Ctr_2 / Ctr_3 | 1.036 / 1.036 / 1.044 | 1.083 / 1.136 / 1.081 |

全部 ≈ 1.0（且处理组与对照组同形）⇒ **该位点在所有样本里都是正常拷贝数**，三体解释不成立。
右侧一致略高（1.07–1.14）在对照里同样出现 ⇒ 是该位点的共有局部特征，不是样本特异信号【推】。

> **⚠ 别拿 `local_baseline_depth_samtools`（44–54）去比 `genome_mean_depth_mosdepth`（22–33）
> 判拷贝数** —— 这两个数**口径不同**：samtools depth 对 mate 重叠双计、mosdepth 校正。
> 本批 insert ≈ 162 bp 而读长 150 bp，重叠极大 ⇒ 两者天然相差约 2 倍，
> 这个 2 倍**是口径差不是拷贝数差**。拷贝数只能用同口径的 `flank_*_norm` 判。
> （这正是 `P46_research_record_1125.md` 结果 1「深度必须双口径报告」那条的同一个坑。）

### 5A.5 换算成细胞比例（这才是客户关心的量）

设群体由「杂合编辑细胞」占比 `x` 与「未编辑细胞」占比 `1−x` 组成（**这是个假设**，
排除了双等位编辑细胞的存在）⇒ 缺失染色体占比 `f_del = x/2` ⇒ **`x = 2 × f_del`**【推】：

| 样本 | `f_del` | 推出的编辑细胞比例 `x` | 读法 |
| :--- | :---: | :---: | :---: |
| Sample_1 | 0.293 | **≈ 59%** | 约四成细胞未编辑 |
| Sample_2 | 0.323 | **≈ 65%** | 约三成半未编辑 |
| Sample_3 | 0.467 | ≈ 93% | 与纯克隆一致 |
| Sample_4 | 0.598 | **≈ 120%（> 100%，不可能）** | 只能解释为纯克隆附近的噪声 ⇒ 与纯克隆一致 |

**Sample_4 这个「超过 100%」本身是个有用的自检**：它说明 `f_del` 的点估计在本深度下
确实能偏到 0.1 量级，与 §5A.3 用对照定出的噪声一致 —— 两条独立的途径给出同一个噪声量级。

### 5A.6 措辞上必须守住的三条

| 不能写 | 要写成 | 为什么 |
| :--- | :---: | :---: |
| 「Sample_1 的缺失是杂合的，占比 29%」 | 「Sample_1 为单等位 Δ202；**该克隆不纯**，Δ202 染色体占比 29%，提示约四成细胞未编辑」 | 29% 不是「杂合的占比」，杂合的占比按定义是 50%；29% 描述的是**细胞混合**，不是等位基因状态 |
| 「Sample_1 不是全部拷贝都带缺失」 | 同上 | 这句话同时可以指等位基因层面和细胞层面，**歧义**，`primer` §4 已列为禁用 |
| 「读段法与深度法两个独立估计（0.29 / 0.32）互相验证」 | 「深度法 0.29 与读段法 0.29–0.32 互证；**0.29–0.32 这个区间是同一个 `J` 配两个切点的分母，不是两次独立测量**」 | `af1`、`af2` **共用分子 `J`** ⇒ 不是独立重复。独立的那一对是**深度法 vs 读段法** |

### 5A.7 残余风险

- **Sample_2 是阈值边缘样本**：`f_del = 0.323` 与阈值 `0.35` 只差 **0.027**，
  约 **0.3 σ**（按 §5A.3 的对照 sd）⇒ **标签可能翻转**。
  它被判亚克隆，真正的支点是读段法 CUT2 的 0.235（p = 0.049）与两法同向，
  **不是** `f_del` 过了阈值这件事。报告里若要给 Sample_2 的比例，**必须带不确定度**。
- **阈值 0.35 / 0.75 是硬编码常数**，未见来自本数据的标定依据【推】。
  当前它只需要把 0.24–0.33 与 0.47–0.61 这两簇分开，**余量足够**；
  但样本量更大、或深度更低的下一批，这个硬阈值需要重新论证。
- 三个对照 **n = 3** 撑起了整篇的噪声标尺。这是目前唯一可用的本底，
  但它既估不出分布形状，也不覆盖处理组可能有的额外变异来源。

## 6. 实现层面的几个判据细节（都有理由，别随手改）

| 判据 | 值 | 为什么是这个 |
| :--- | :---: | :---: |
| 跨越读段要求双侧锚定 | 起点 ≤ cut−15、终点 ≥ cut+15 | 只有真正**骑住**切点才算跨越；靠边的比对无法区分「此处完整」与「此处是断端」 |
| 跨越读段要求 `maxclip < 20` | 20 bp | 把**接头读段**排除在跨越读段之外，否则同一条分子会被两类证据**重复计入** |
| 「切点附近」的宽度 | ±10 bp（`INDEL_SLOP`） | NHEJ 产物与比对器对 indel 的放置都有几 bp 游动；太窄会漏、太宽会把无关 indel 算进来 |
| 判「该切点带 indel」的条件 | `indel > 0` **且** `indel ≥ clean` | 零星几条 indel 读段可能是比对/测序噪声或第三个亚克隆；要求它**占优**才认定为该等位的状态【推】 |
| 计数单位 | **read name 去重**（`len({...})`） | 分子数按 read name 计，一个片段只算一次 |
| 但 alignment record **全部留档** | `supplementary_alignments.tsv` 等 | §2A：supplementary **不是**独立分子，**却是** split/chimeric 结构的直接证据，不得因「不是独立分子」而丢弃 |

**`J`、`clean`、`indel` 三者的分子关系**（理解这个就不会把它们混用）：
- `J` 数的是**已缺失**等位的分子；
- `clean` + `indel` 数的是**未缺失**等位的分子；
- 两者之和 ≈ 该位点总覆盖分子数 ⇒ `J/(J+clean)` 才是「缺失等位占比」的读段法估计。
  Sample_5 的 `J/(J+clean)` 在 CUT1 处等于 1.000，**并不代表双等位缺失**，
  而是因为 CUT1 的 `clean` 为 0 —— 分母里那一项被 indel 吃掉了。
  **⇒ 这个比例必须与同切点的 `indel` 数一起读，单看会反向误导。**

## 7. ⚠ 外部定标断言**抓不到**这个错 —— 实测核对

`11_stage1_ontarget.py:421-441` 有一条硬断言，拿客户凝胶/Sanger 的先验基因型校流程。

if prior in ("mono","bi") and c.startswith("WT"):       → 记为不一致（假阴性）

## 8. 推广形式：这条规则不只适用于双切

**一般陈述**：

> **当"判定单位"的跨度大于"观测单位"的跨度时，判定单位内部的两个特征在该数据里
> 永不共观测；任何关于"它们处于同一个判定单位上"的陈述都是推断。
> 这个推断必须按位置分别统计、再显式联合 —— 跨位置求和会把携带相位的那个变量
> 边缘化掉，此后无论怎么设阈值都无法恢复。**

套用到别的场景：

| 场景 | 判定单位 | 观测单位 | 不能求和的那个维度 |
| :--- | :---: | :---: | :---: |
| 双切片段缺失（本文） | 等位基因 | 读段（150 bp） | **切点位置** |
| 复合杂合（compound het） | 等位基因 | 读段 | **两个变异位点各自的位置** |
| 多外显子事件 | 转录本 | 读段 / 片段 | **外显子编号** |
| 多位点整合 | 单个整合事件 | 读段 | **junction 侧别（左/右断端）** |
| 多切点脱靶成对位点 | 一个脱靶事件 | 读段 | **成对切点的两侧** |

**可操作的自检问句**（动手写聚合代码前问一遍）：

1. 我要判定的命题，是关于**一条分子**的，还是关于**一堆读段**的？
2. 命题里涉及的几个特征，**有没有任何一条观测同时覆盖它们**？
   —— 没有 ⇒ 相位不可观测 ⇒ **禁止跨这些特征求和**。
3. 我的聚合（`sum` / `groupby().agg()` / 合并列）**抹掉了哪个标签**？
   那个标签是不是命题所必需的？
4. 有没有**平行的估计量**（深度法 vs 读段法、逐切点 vs 合并）？
   **它们的量级反差是最好的探测器** —— 一致才说明不是方法偏差，
   反差大就必须找出反差来自哪个维度。
