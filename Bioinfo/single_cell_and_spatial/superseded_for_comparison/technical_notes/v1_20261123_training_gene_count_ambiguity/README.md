## 归档原因

修改前，§0 将去卷积训练基因条件概括为“训练基因数 > 0”，容易被理解为一个基因就足以支持分析。§4.6 的代码实际使用 `n_train >= 100`，但没有说明这只是本地流程的预检下限，也没有区分“非空输入”和“有足够判别信息”。

## 修改内容

修订版将说明：`n_train > 0` 只能拦截空输入；单基因通常不足以稳定区分多个细胞类型；文中 `shared >= 1000` 和 `n_train >= 100` 是本地流程阈值，不是跨方法通用的充分性保证。还补充了达到预检下限后需评估签名可区分性与结果稳定性。
