# 空间转录组：测序型平台与成像型平台的区别

> 2026-11-19 · 内部技术笔记 · 与 `/spatial` skill §1「平台分流」一致

## 结论

两类平台的根本区别在于**读出方式**：测序型用条形码记录位置，再把文库拿去测序；成像型在显微镜下直接看到每一个转录本分子。读出方式不同，后面几件事就跟着不同：观测单位、基因覆盖、分辨率，以及分析里最难的那一步。所以要把它们当成**两条独立的管线**，不能当作一条管线换个参数。

- **测序型**：全转录组、无偏发现；观测单位是 spot/bin，**不是细胞**；核心难题是**去卷积**。
- **成像型**：panel 基因、亚细胞分辨率；观测单位是转录本分子；核心难题是**分割**；**"未检出"常常是 panel 里没有这个基因**。

## 1. 原理

| | ① 测序型（sequencing-based） | ② 成像型（imaging-based） |
| :--- | :---: | :---: |
| 代表平台 | Visium、Visium HD、Slide-seq、Stereo-seq | Xenium、CosMx、MERFISH/MERSCOPE |
| 怎么记录位置 | 玻片上铺满带**空间条形码**的捕获探针。组织里的 mRNA（或 FFPE 用的探针）被原位捕获，带上所在位置的条形码，然后建库、测序 | 用**原位杂交探针**结合目标 RNA，经过多轮杂交和成像，按荧光编码解码出每个分子是哪个基因 |
| 怎么判定基因身份 | 测序 read 比对到参考基因组 | 荧光组合编码（MERFISH 的组合条形码带纠错；Xenium 是挂锁探针加滚环扩增，再循环解码） |
| 原始数据 | FASTQ → spot/bin × gene 的计数矩阵，外加 H&E 图像 | 多轮荧光图像 → **转录本坐标表**（每个分子一行：x、y、z、基因、质量分），外加 DAPI 或膜染色图像；数据量常在数百 GB 到 TB 级 |

## 2. 由读出方式决定的关键差异

| 维度 | 测序型 | 成像型 |
| :--- | :---: | :---: |
| **观测单位** | **spot / bin，不是细胞**。Visium 一个 55 µm 的 spot 里有几个到几十个细胞 | **单个转录本分子**，要靠分割归到细胞里 |
| **基因覆盖** | **全转录组**，无偏，适合发现 | **panel**，从数百到数千基因（近年到 5000–6000 级），只能看预先选定的基因 |
| **空间分辨率** | Visium 55 µm；Visium HD 2 µm bin；Stereo-seq 亚微米级 DNB | 亚细胞级，能分出核内和胞质 |
| **单个基因的检测灵敏度** | 较低，捕获效率有限；HD 的 2 µm bin 里中位计数只有个位数 | 对 panel 内的基因通常更高、更定量 |
| **分析的核心难题** | **去卷积**：一个 spot 里混了哪些细胞类型、各占多少 | **分割**：哪些转录本属于同一个细胞 |
| **主要技术误差** | 转录本侧向扩散，相邻 spot 互相混入；组织外背景；spot 混合信号 | 分割错误，相邻细胞的转录本被错配；光学拥挤；spillover（信号串扰） |
| **"未检出"的含义** | 通常是低表达或没捕获到 | **常常是 panel 里根本没有这个基因**，不能读成"不表达" |
| **成像面积和通量** | 一张捕获区域，组织大小受限 | 一张玻片可以覆盖较大面积，但耗时长、成本随面积和 panel 增加 |
| **适合的科学问题** | 无偏发现：组织区域的整体转录特征、空间可变基因、新通路 | 已有假说下的验证：细胞类型精确定位、细胞邻域、细胞间空间关系 |

## 3. 下游分析几乎没有交集

| 分析步骤 | 测序型 | 成像型 |
| :--- | :---: | :---: |
| QC | 先按 `in_tissue` 过滤，再看 spot 的 counts/genes/mito 和空间局部异常 | 转录本质量分、negative control 探针、分割后每个细胞的计数和面积 |
| 获得"细胞" | 做不到（Visium），或者从 2 µm bin 重建细胞（Visium HD：bin2cell、StarDist） | 接受厂商分割，或自己重做（Sopa + Proseg/Baysor/Cellpose） |
| 细胞类型组成 | **去卷积**（RCTD、Tangram、cell2location），**必须有同组织的 scRNA 参考** | 分割后直接注释，或做 label transfer |
| 必须做的稳健性检查 | 去卷积两种方法并跑，逐细胞类型比 Spearman | **分割敏感性分析**：换一种分割设置，看细胞比例和组间差异方向是否稳定 |
| 报告里必须声明的 | 观测单位是 spot；去卷积比例是模型估计，不是观测 | 分割来源；panel 的覆盖范围；"未检出 ≠ 不表达" |

## 4. 两类平台的边界在变模糊，但分界没有消失

- **Visium HD 和 Stereo-seq 的分辨率已经接近单细胞**，但它们给的仍然是"每个 bin 的计数"。单个 bin 计数太低，做不了统计，默认分析尺度是 8/16 µm；2 µm bin 的真正用途是**作为细胞重建的输入**。所以测序型做到高分辨率之后，同样要面对分割问题。
- **成像型的 panel 越来越大**，5000 基因级已经接近"半转录组"，但仍然是预选的基因，不能替代无偏发现。
- 实际项目常常**两者配合**：测序型做全转录组发现，成像型在同一组织的相邻切片上做高分辨率验证。

## 5. 选平台时最先问的一个问题

**"我是要发现未知的基因，还是要精确定位已知的细胞？"**

- 要发现未知基因，选测序型。代价是观测单位不是细胞，必须去卷积，而且需要同组织的 scRNA 参考。
- 要精确定位已知细胞，选成像型。代价是只能看 panel 里的基因，而且所有细胞级结论都依赖分割。
