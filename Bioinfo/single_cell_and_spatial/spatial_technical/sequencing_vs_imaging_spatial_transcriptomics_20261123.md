# 测序型与成像型空间转录组：原理与分析方法差异

> 建于 2026-11-23。本文只比较测量原理、数据对象和分析方法，不展开平台选型、软件生态或实验操作流程。

## 范围与术语

本文将**测序型**限定为常见的空间条码捕获后建库测序路线：先用 spot、bin 或 bead 等空间单元记录位置，再通过测序读出基因。Visium、Slide-seq 和 Stereo-seq 是这一大类中的例子。**成像型**指在组织原位用基因特异性探针识别转录本、经荧光成像和解码得到分子坐标的路线，例如 Xenium、CosMx 和 MERFISH。

这是一种便于讨论分析差异的工作分类，不代表领域里只有两种化学路线。部分方法直接在组织原位进行测序或测序式解码，可能同时具有两类特征；遇到这类方法时，应按实际输出的数据对象判断分析流程，而不是只看平台名称。两类技术的核心区别是：**空间位置是由捕获单元的条码还原，还是由成像直接定位转录本。**[1–4]

## 1. 测量原理与数据对象

| 比较维度 | 测序型：空间条码捕获后测序 | 成像型：原位探针与光学解码 |
| :--- | :---: | :---: |
| 如何识别基因 | 捕获到的 RNA 或目标序列进入测序文库，由测序读段识别基因；具体捕获化学因平台而异 | 基因特异性探针与目标 RNA 结合，经多轮荧光成像和编码解码识别转录本 |
| 如何确定位置 | 测序读段携带空间条码；条码映射回载片上的 spot、bin 或 bead 坐标 | 在组织图像中直接检测每个转录本的位置坐标，再将各轮图像配准并解码 |
| 直接输出的观测对象 | 每个空间捕获单元中的基因计数 | 带有基因身份和 x/y（有时 z）坐标的转录本记录 |
| 常见分析矩阵 | 基因 × spot/bin/bead 的计数矩阵 | 解码后的转录本坐标表；完成细胞分割和分配后，可形成基因 × 细胞矩阵 |
| 典型覆盖特点 | 常见捕获型设计覆盖较广，可用于较开放的转录组探索；具体是否全转录组取决于捕获化学和探针设计 | 通常是预先定义的目标基因 panel；可在原位精确定位 panel 中的转录本 |
| 默认空间尺度 | 由 spot、bin 或 bead 的大小和排列决定；一个观测单元不自动等于一个细胞 | 转录本可有分子级坐标；要形成细胞级表达量，仍需定义细胞边界并将转录本分配给细胞 |

捕获型空间条码与测序读段结合的基本思路见最初的空间转录组研究及 Visium 技术说明。[1,2] MERFISH 等原位成像方法则通过多轮编码读出基因身份和分子位置；Xenium 官方流程也展示了探针杂交、扩增、成像和解码等环节。[3,4]

## 2. 两条典型分析链

### 2.1 测序型

**空间条码 / 测序文库 → 基因计数与坐标表 → spot/bin 级 QC → 归一化与降维 → 空间域和空间可变基因 → 按问题做去卷积、区域比较或细胞重建。**

- **输入和预处理：**测序读段、空间条码与组织图像；进行基因计数、条码和坐标对应、组织区域识别，以及组织图像与阵列坐标的配准。
- **QC重点：**每个 spot/bin 的 UMI 与基因数、测序和比对质量、组织内外判定、坐标完整性，以及局部低质量区域是否来自组织损伤或技术问题。
- **常见下游：**空间域识别、空间可变基因（SVG）、区域表达比较。若研究问题要求解释混合 spot 中有哪些细胞类型及其比例，可用参考依赖的去卷积；去卷积是模型估计，不是直接观测。
- **高分辨率数据：**bin 可以先合并到较大空间单元以增加计数；若要得到细胞级矩阵，则需额外做细胞边界分割和 bin/转录本归属。细小 bin 的坐标更精细，但 bin 本身仍不是细胞。[6]

### 2.2 成像型

**循环成像 → 图像配准与转录本检测 → 基因解码和分子坐标表 → 细胞/细胞核分割与转录本分配 → 细胞级 QC → 细胞类型、邻域和空间关系分析。**

- **输入和预处理：**多轮图像及解码结果；先做图像配准、信号检测与解码，生成包含基因身份、坐标和质量信息的转录本记录。
- **细胞级矩阵：**用细胞核或细胞边界将组织划分为细胞，再把每个转录本分配给细胞并汇总成基因 × 细胞计数矩阵。直接的转录本坐标分析不一定需要分割；但细胞类型比例、细胞级表达和细胞邻域问题通常需要明确的细胞边界。
- **QC重点：**图像轮次间配准、解码置信度、阴性/背景信号、未分配转录本比例、细胞边界质量和每细胞计数。分割或分配规则会改变哪些转录本计入哪个细胞，可能进一步改变细胞数、类型比例和邻域结果。
- **常见下游：**细胞类型注释、细胞密度与空间分布、邻域/共定位分析、细胞间空间关系，以及 panel 范围内的 SVG。由于 panel 是预先限定的，矩阵中没有某个基因可能表示该基因未被检测设计覆盖，不能直接解释为组织中不表达。

## 3. 分析方法为何不同

| 分析问题 | 测序型的主要处理 | 成像型的主要处理 |
| :--- | :---: | :---: |
| “这个位置有哪些细胞？” | spot/bin 可能混合多个细胞；若要估计组成，需去卷积或用细胞重建方法，并说明参考数据和模型假设 | 先将转录本分配到分割后的细胞，再依据表达、参考数据或形态信息注释细胞类型；分割和 panel 共同限制可识别的细胞类型 |
| “哪些基因在空间上有结构？” | 在 spot/bin 坐标上检验空间结构；方法需考虑计数稀疏、捕获尺度和空间自相关 | 在转录本坐标、细胞坐标或细胞邻接图上检验；应说明分析所用空间层级及分割结果的影响 |
| “细胞如何彼此邻近？” | 常规 spot 数据只能描述空间单元之间的邻近；要讨论细胞邻近，需先去卷积/重建细胞，或使用足够高分辨率的分割结果 | 可直接利用细胞坐标和边界构建邻接关系；邻近或表达共现支持空间关联，本身不证明分子通讯或因果作用 |
| “条件之间哪些基因不同？” | 在区域或细胞类型层面构建可比较的表达量；spot/bin 嵌套于样本，不能把每个 spot 当成独立生物学重复 | 可在细胞类型或区域内汇总细胞表达；细胞嵌套于样本，不能把每个细胞当成独立生物学重复 |
| “能否发现未预设的基因？” | 常见全转录组捕获路线适合较开放的发现；仍受捕获效率、测序深度和检测限影响 | 通常受 panel 限制；没有纳入 panel 的基因无法从该数据中作阴性判断 |

## 4. 两类数据共有的统计原则

**spot、bin、转录本和细胞是测量层级，不自动等于独立生物学重复。**跨条件推断的独立单位通常是动物、供体或样本；分析应按实验设计采用样本级汇总（如 pseudobulk）或合适的层级模型。把同一张切片上的大量 spot 或细胞当作独立重复，会造成伪重复。

两类数据都可做空间域和 SVG 分析，但不能只因方法名称相同就直接复用同一套输入假设：测序型通常面对捕获单元上的聚合计数，成像型通常面对分子坐标或经分割得到的细胞对象。分析前要写明观测单位、坐标来源、过滤规则及分割/去卷积是否改变了观测对象。

## 5. 一句话总结

**测序型先把空间位置编码进捕获条码，再由测序读出基因；成像型先在组织原位识别并定位目标转录本。**因此，测序型分析的关键常是 spot/bin 的混合表达与去卷积，成像型分析的关键常是转录本解码、细胞分割和分配。两者的 QC、矩阵含义和统计单位都应按各自的测量过程定义。
