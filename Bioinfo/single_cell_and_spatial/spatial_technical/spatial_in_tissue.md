spatial 转录组 in_tissue 过滤是什么意思

在空间转录组（Spatial Transcriptomics，最常见于 10x Genomics Visium 平台及下游的 Space Ranger、Scanpy / Squidpy、Seurat 分析流程）中，in_tissue 过滤指的是：根据捕获点（Spot）是否落在组织切片区域内，筛掉位于空白玻片/组织外的背景 Spot，只保留真正覆盖在组织上的有效 Spot。

1. in_tissue 字段代表什么？
   在 Visium 的空间位置文件（如 tissue_positions_list.csv 或 tissue_positions.parquet）中，芯片表面排布着成千上万个带有空间坐标的捕获点（Spot）。由于组织切片通常无法填满整个捕获区，每个 Spot 会被标记一个二值状态：

in_tissue = 1（或 True）：该 Spot 位于组织切片区域内，其捕获到的 RNA/UMI 主要来自组织细胞，是下游分析的核心对象。

in_tissue = 0（或 False）：该 Spot 位于组织区域之外（空白区域、玻片背景或组织边缘外的脱胶区）。

它是如何判定的？ 通常由 Space Ranger 结合组织染色图像（如 H&E 或 IF 图像）与 Spot 阵列对齐后自动识别；在部分自定义流程或图像配准偏差较大时，也可能结合图像分割或 UMI 分布进行校正。

2. 为什么要做 in_tissue 过滤？
   去除环境噪声与背景 RNA：空白区域的 Spot 理论上没有细胞，但实际测序中仍可能检出少量游离 mRNA（ambient RNA）、扩散 RNA 或测序错误/Index hopping 带来的假阳性计数。不过滤会引入背景噪音。

加速下游计算并避免干扰降维/聚类：组织外 Spot 数量不少，剔除它们可以减少内存与计算开销，避免低质量或无意义背景点扭曲 PCA、UMAP、空间聚类（如 SpaGCN、Banksy）或空间高变基因（SVG）识别。

对齐组织病理结构：保证后续空间域划分、配体-受体互作或细胞类型反卷积（如 RCTD、cell2location）只发生在真实生物学组织空间内。

实际分析中的几个关键细节
先 in_tissue 过滤，再做常规质控（QC）：建议先保留 in_tissue == 1 的 Spot，再结合 total_counts、检出基因数（n_genes_by_counts）和线粒体比例做质控，这样统计指标更能反映真实组织质量。

警惕图像对齐偏差（Tissue Alignment 误差）：如果组织边缘染色较浅、切片有褶皱或撕裂，自动识别可能把边缘真实组织 Spot 误判为 0，或把少量组织外 Spot 误判为 1。发现边缘出现“缺口”或异常 Spot 时，应回看 H&E 图像与 Spot 叠加图（Loupe Browser / sc.pl.spatial）确认。

不同平台的差异：in_tissue 这一列名和布尔/0-1 标记最典型地出现在 Visium 体系中；如果是高分辨率成像或纳米孔/网格类平台（如 Visium HD、Stereo-seq 等），底层逻辑类似，但组织掩膜（tissue mask）或 bin/细胞分割后的过滤字段与粒度会有所不同。

1. in_tissue 过滤后的常规质控阈值设定空间转录组与单细胞转录组（scRNA-seq）的核心差异在于：
   每个 Spot 可能包含 1 个或多个细胞（甚至跨细胞边界），且不同解剖区域（如致密神经核团、肿瘤核心、坏死区、脂肪/白质）的转录活性天然差异很大。

因此，切忌照搬单细胞或单一固定阈值直接一刀切，应先看分布、分样本/分区域评估。

实操设定建议

1. 先分样本独立计算：不同切片、批次、捕获区域或 FFPE vs. Fresh Frozen 样本的测序深度和背景不同，务必逐张切片查看分布，不要跨样本用同一个硬阈值。
2. 结合空间位置看“被过滤掉的点”：在空间图（如 sc.pl.spatial 或 Loupe Browser）上把拟剔除的低质量 Spot 高亮出来。如果某整片解剖结构（例如致密白质、坏死区、特定脑区或脂肪层）被整块砍掉，说明阈值过严，需要下调或分区域调整。
3. 采用数据驱动 + 适度宽松原则：常用做法是结合 MAD（中位数绝对偏差，如低于中位数减去 3 个 MAD）与最低保底值（如 min_genes >= 200 或 300）。空间分析中通常比单细胞更保守（阈值更宽松），因为 Spot 聚合了局部信号，过度过滤容易破坏空间连续性和边缘结构。
4. 先看指标联合分布再删点：重点观察 total_counts 与 n_genes_by_counts 的相关性，以及高 pct_counts_mt 是否集中在低 count 区域，避免误杀高代谢正常组织。
5. Tissue 识别或图像对齐不准导致边缘 Spot 丢失的排查与处理当组织切片边缘染色较浅、存在折痕/撕裂/气泡，或图像分辨率与坐标变换矩阵偏差时，自动流程可能把真实位于组织边缘的 Spot 标为 in_tissue = 0，造成空间图边缘出现“缺口”或锯齿状丢失。可按以下顺序排查与修复：1.叠加检查组织图像与 Spot 坐标:第一步 · 定位偏差类型.在 Loupe Browser 中打开 .cloupe 文件，或用代码将 in_tissue == 0 与 in_tissue == 1 的 Spot 叠加在 H&E/IF 组织图像上放大查看边缘。Verification: 能够明确看出丢失 Spot 是因为“组织掩膜没框住边缘”，还是“整个 Spot 网格整体偏移/旋转/缩放错位”。2.核查 UMI 与基因数是否藏着真实信号:第二步 · 确认是否为假阴性.查看被判为 in_tissue = 0 但紧邻组织边缘的 Spot 的 total_counts 与 n_genes_by_counts。若这些 Spot 具有明显高于空白背景的 UMI 数或清晰的空间标记基因表达，说明属于边缘漏检。Verification: 边缘 in_tissue = 0 的 Spot 出现连续的 UMI 升高或符合邻近组织特征的基因表达，而非纯随机零星噪声。3.重新调整图像对齐或手动修正组织标注:第三步 · 修复对齐或重标 Spot.若存在整体错位或旋转，需重新校准图像对齐（如在 Loupe Browser 中重新执行 fiducial/对齐调整，或在 Space Ranger 中检查输入图像方向、缩放与对齐参数）；若仅是局部边缘染色浅导致自动识别漏选，可在 Loupe Browser 中手动将漏选的边缘 Spot 标记为组织内，并导出更新后的 tissue positions / 注释文件。Verification: 放大观察组织边缘，染色清晰且有细胞的边缘 Spot 均被正确纳入有效区域，网格与组织边界贴合。4.重新生成或更新分析矩阵并复核下游结果:第四步 · 同步下游分析.将修正后的组织位置表或 Spot 筛选结果重新导入下游流程（重新执行 in_tissue 过滤、质控与空间聚类），对比修正前后的边缘聚类与空间表达图。Verification: 边缘“缺口”消失，下游聚类边界更连贯，且没有引入大量空白背景 Spot 干扰结果。
