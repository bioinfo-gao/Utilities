# 单一条件下不存在"差异"：切片间差别 ≠ 处理效应

> 2026-11-20 建。出处：[../spatial_analysis_best_practices_20260917.md](../spatial_analysis_best_practices_20260917.md) §1.3 末段的展开讲解。

## 结论

**单一条件下不存在"差异"这个问题**，不要用切片之间的差别冒充组间差异——
**那是个体差异 + 批次，不是处理效应。**

这是实验设计问题，不是统计方法问题：没有对比，就没有差异可言。

---

## 1. 为什么单一条件下没有"差异"

处理效应（treatment effect）只能从两个条件的对比里定义（KO vs WT、处理 vs 对照）。
所有样本都来自同一个条件时，`condition` 列是常数：

```r
design = ~ condition      # condition 全是 "WT"
# 该列与截距完全共线 → 系数不可估计
```

这不是统计功效不足，而是参数**不可估计（not identifiable）**：可以拟合出数字，
但没有一个数字代表"处理的作用"。

## 2. 切片之间的差别从哪里来

同一条件下有 4 张切片，它们之间的差别（某 domain 比例不同、某些基因整体高低不同）可分解为：

| 来源 | 含义 | 是否属于处理效应 |
| :--- | :---: | :---: |
| 个体差异（biological variation） | 不同动物/供体之间本来就不一样 | 否 |
| 切面位置（section plane） | 切到组织的不同深度或区域，组织构成本身不同 | 否 |
| 技术批次（batch） | 切片、固定、透化、capture area、建库、测序 run 不同 | 否 |
| 处理（treatment） | 本数据里不存在 | — |

拿"切片 A vs 切片 B"跑 DE，得到的显著基因是前三行混在一起的结果。
用 DE 的形式报出来，读者会自然理解成"有一个生物学因素导致了这些变化"——这就是"冒充"：
**形式是组间比较，内容是噪声结构。**

### 伪重复（pseudoreplication）放大了这个错误

spot / 细胞数以千计，若把它们当独立观测比较两张切片，几乎任何基因都会显著。
真正的独立单位是**切片或个体**，不是 spot。p 值极小在这里不是证据强，而是分母用错了。

## 3. 反过来同样危险：条件与切片完全混杂

即使有两个条件，若每个条件只有 1 张切片（或 1 个个体）：

```
WT = slice1（个体1, 批次1）
KO = slice2（个体2, 批次2）
```

条件、个体、批次三者完全混杂（confounded），"KO vs WT 差异"与"slice2 vs slice1 差异"
在数学上是同一个量。要分开它们，每个条件需要 ≥2 个独立生物学重复，并尽量在批次上平衡设计。
（对应 §1.3 的判定：≥ 2 组 × ≥ 2 生物学重复才可做组间比较。）

## 4. 单一条件下能做什么

不能做"差异"，但描述性分析与条件内部分析都成立：

| 可以做的分析 | 回答的问题 | 证据单位 |
| :--- | :---: | :---: |
| 空间 domain / 细胞类型注释与分布 | 组织里有什么、在哪里 | 切片内 |
| 切片内区域之间的比较（domain A vs domain B） | 组织内部的空间分区 | 切片内，且须在每张切片上重复出现 |
| SVG（spatially variable genes） | 哪些基因有空间结构 | 切片内 |
| 细胞类型邻近关系 / 配体-受体分析 | 谁和谁相邻、可能的相互作用 | 切片内 |
| 跨切片一致性 | 上述结论是否在每张切片上都复现 | 以切片为单位计数 |
| 方差分解（切片/个体占多少变异） | 本体系本底噪声多大，为后续实验算样本量 | 切片/个体 |

第 2 行合法，是因为比较发生在同一张切片内部，个体与批次被自然控制。
**判据是"每张切片上方向一致"**，而不是把所有 spot 合并算一个 p 值。

## 5. 报告里怎么写

| 不应该写 | 应该写 |
| :--- | :--- |
| "Slice 2 shows upregulation of X compared to Slice 1" | "Expression of X varied between sections; with a single condition, this variation reflects inter-individual and technical differences and cannot be attributed to any experimental factor." |
| 在 Results 里给"切片间 DE 基因列表" | 在 QC / 可重复性部分报告切片间一致性或方差组成 |

## 一句话

**差异需要一个变化的因素；单一条件下，切片间的差别只是本底——用来估计噪声、检验可重复性，不是用来报告的发现。**
