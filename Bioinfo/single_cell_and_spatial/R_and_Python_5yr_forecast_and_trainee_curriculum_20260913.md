## §0 结论先行（只读这一节也够用）

### 0.1 给新人的一句话

**以 Python(scverse) 为唯一主线学到"能独立完成一个项目"的深度；
R 只学三块、只学到"能读懂 vignette 并改参数跑通"的深度，永远不要学第二遍全栈。**

### 0.2 R 要学的就是这三块，别再多

| 块 | 内容 | 学到什么程度 | 五年后还在吗 |
| :--- | :---: | :---: | :---: |
| ① 跨条件差异表达 | DESeq2 / edgeR / limma 跑 pseudobulk；公式接口 `~ group + (1\|donor)` 的含义 | 能把一个 counts 矩阵 CSV 读进去、写对 design、解释结果 | **很可能在**（最可能翻盘的一块） |
| ② 空间统计 | spdep / nnSVG / Banksy / spacexr，**仅当你真的做空间** | 能跑通并解释邻域统计与去卷积的输出 | **很可能在**（风险不在技术，在 Bioconductor 的维护） |
| ③ 出版级绘图 | ggplot2 + ComplexHeatmap | 能改别人的脚本出图，不必从零写 | **在，但差距在收窄** |

**明确不用学**：Seurat 全栈流程、R 包开发与 S4、Shiny、tidyverse 全家桶、
`rpy2` / `reticulate` 这类进程内互操作（后者在任何时候都不要用，见 §5.4）。

### 0.3 但最重要的一条不是语言

**在五年尺度上，"学哪个语言"的重要性正在下降，"懂不懂统计与实验设计"的重要性没有变。**
大语言模型（LLM）已经把"把想法翻译成某语言的代码"的成本压得很低，并且还会继续下降；
它压不低的是"知道这个对比根本没有生物学重复""知道这里必须做 pseudobulk 否则是伪重复"。
**建议的精力分配：方法学与统计 50% / Python 30% / 工程可复现性（git、环境、流程管理）20%，
R 从那 30% 里挤出十几个小时即可。**

## §1 为什么这个问题必须现在回答

博士周期 5–5.5 年意味着一件事：**一年级做的技术栈选择，在四五年级写论文时才兑现。**
如果按今天的生态做选择，学生会在一个已经开始衰退的生态上花掉不可回收的两年。

反过来，这也意味着**判断错误的代价是不对称的**：

| 判断错误的方向 | 后果 | 可恢复性 |
| :--- | :---: | :---: |
| 押 Python，但五年后 R 仍是主流 | 需要补学 R，但 R 的门槛低于 Python，且新人的统计基础已经建立 | **可恢复**（几个月） |
| 押 R，但五年后 Python 一统 | 深度学习方法、大规模数据、公共 atlas 全部读不进来；这些不是"补学一个包"能解决的 | **代价高**（重建整套工作流） |

**⇒ 即使我的预测只有六成把握，押 Python 仍然是正确的决策**——因为两个方向的错误成本不对称。
这条推理不依赖预测本身的准确性，是本文最稳的一条。

## §2 五年预测：逐环节

**判据说明**：下表的"2031 预测"指的是**那时的主流做法**，不是"那时还有没有人在用"。
R 在 2031 年当然还有人用；问题是新人要不要为它花时间。

| 环节 | 2026 现状【事实】 | 2031 预测【判断】 | 我的置信度 |
| :--- | :---: | :---: | :---: |
| 数据读写 / 对象模型 | `h5ad` + `zarr` 已是跨语言交换格式；R 侧三个对象模型并存 | **Python 压倒性** | 高 |
| 质控 / 归一化 / 聚类降维 | 两边算法同源，能力对等 | Python 压倒性（惯性，非能力差） | 高 |
| 批次整合 | Harmony / scVI / Seurat 三足鼎立 | **Python 压倒性** | 高 |
| 深度概率建模 | scvi-tools 全家无 R 原生对等物 | **R 完全出局**，只能当调用方 | 很高 |
| 超大规模 / out-of-core | Python 惰性数组成熟；R 侧 BPCells 是孤例 | **Python 压倒性** | 高 |
| 细胞注释 | R 侧 Azimuth / ProjecTILs 仍强 | **被基础模型抹平**，语言之争失去意义 | 中 |
| **跨条件差异表达（pseudobulk）** | DESeq2 / edgeR / limma 是审稿共识锚点 | **R 仍是默认**；PyDESeq2 成熟度是最可能翻盘的一块 | 中 |
| 混合效应 / 复杂实验设计 | 公式接口是 R 的语法层原生能力 | **R 仍有优势**，但差距收窄 | 中 |
| 空间：数据结构与多模态 | SpatialData 统一了 image + shape + table | **Python 赢定**（工程问题，不是统计问题） | 高 |
| 空间：细胞分割 | 分割工具本身是多语言 CLI，但编排在 Python | **Python 单极** | 高 |
| **空间：邻域 / 点过程统计** | R 有三十年 spdep / spatstat 传统 | **R 仍有优势**，是三块里最保值的一块 | 中低 |
| 空间：去卷积 | 两边都有可用实现 | 打平 | 中低 |
| 轨迹 / RNA velocity | Python 是参考实现；R 强在沿轨迹的统计检验 | Python 优，R 保留统计那一格 | 中 |
| **出版级绘图** | ggplot2 / ComplexHeatmap 仍明显更好 | **R 保留优势但差距收窄**；黏性来自人不来自工具 | 中 |

## §3 支撑判断的三条结构性理由

这三条比"哪个包更多"重要得多，因为它们解释的是**为什么趋势不会自己反转**。

### 3.1 格式即权力

【事实】主要公共 atlas（Human Cell Atlas、CZI CELLxGENE 等）的官方分发格式是 `h5ad`，不是 `.rds`。
【判断】谁掌握交换格式，谁就决定下游生态往哪长。R 侧的 `zellkonverter` 是**转换器**，
而转换器永远是二等公民——它总是滞后于源格式的新特性，且每次格式演进都要重新适配。

### 3.2 方法首发地已经单极化

【事实】新方法先出 Python 版、一两年后（或永远不）出 R 包。
【判断】这个时滞在 2023 年还是半年量级，现在接近"不移植"。
做前沿分析的人等不起，而博士生的课题几乎总是要用到发表不到两年的方法。

### 3.3 R 的不可替代件全在"统计传统"一侧，而统计传统不生长

【判断】`spdep` / `spatstat` / `sf` 是三十年的空间统计积累，`limma` / `edgeR` 是二十年的
微阵列统计遗产加上随之形成的审稿共识。这类资产**不会因为 Python 生态活跃就被复制出来**——
它们的护城河是审稿人的习惯，不是代码。
**但同样地，它们也不生长**：新的方法学增量几乎全部发生在 Python 一侧。
⇒ R 的地盘是一块**稳定但不扩张**的飞地。这正是"只学三块"的依据。

## §4 对原始命题的校正

原始提法是："R 在专业生物信息学分析人士中基本消失，只存在于从实验转入的或只做部分分析的人士中。"

**方向对，但有一半是反的。**

| 提法 | 判定 | 理由 |
| :--- | :---: | :---: |
| "纯 R 全流程的专业人员会消失" | **✅ 同意** | 这是本文的核心预测 |
| "从实验转入的人更黏 R" | **✅ 同意** | Seurat 单包成套、教程多、不用管环境依赖，对非计算背景的人门槛最低 |
| "只做部分分析的人才用 R" | **❌ 方向相反** | 恰恰是**做全套**的专业人员才需要 DESeq2 / spdep / ComplexHeatmap；只做部分分析的人更可能只跑一个 Seurat 教程就停下 |
| "R 基本消失" | **⚠️ 过强** | 消失的是"R 程序员"这个**身份**，不是 R 这个**工具** |

**更准确的表述**：
> 五年后不会有人把自己描述成"我用 R 做单细胞"，
> 但很多人的流程里第 7 步还是会跑一个 `DESeq2::results()`。

## §5 给新人的具体学习清单

### 5.1 Python 主线：学什么、什么顺序

**关键认知：根是数据模型，不是某个包。** 先理解 AnnData 的结构（`X` / `obs` / `var` /
`obsm` / `layers` 各自放什么），后面所有包都是围绕它转的。很多人直接从 scanpy 的
教程第一行抄起，结果两年后仍然不知道自己在操作什么。

| 阶段 | 内容 | 建议投入 |
| :--- | :---: | :---: |
| 1 | Python 基础 + numpy / pandas；**不要学到写类和装饰器** | 2–3 周 |
| 2 | **AnnData 数据模型**（`h5ad` 的结构，读写与切片） | 3–5 天 |
| 3 | scanpy 全流程：质控 → 归一化 → 高变基因(HVG) → 降维聚类 → marker | 3–4 周 |
| 4 | 环境与可复现性：mamba / uv、git、Jupyter 与脚本的分工 | 持续 |
| 5 | scvi-tools：至少 scVI / scANVI 会跑、会判断收敛与整合是否过度 | 2–3 周 |
| 6 | 空间（**仅当课题涉及**）：SpatialData + squidpy | 3–4 周 |

### 5.2 R 三块：怎么学到"够用"就停

**目标不是会写 R，是会读懂并修改一份 R 脚本。** 具体判据：
拿到一份别人的 `.R`，能说出每一步在做什么、能改掉里面的文件路径与 design 公式、
能把报错读懂。**不需要**能从零写一个 R 包，**不需要**懂 S4 的方法分派。

| 块 | 最小学习路径 | 建议投入 |
| :--- | :---: | :---: |
| ① pseudobulk 差异表达 | R 语法极简入门 → 读懂 DESeq2 vignette → 用自己的数据跑一遍 | 1 周 |
| ② 空间统计（仅当需要） | 先理解"空间统计不是多了两列坐标" → OSTA 相关章节 | 2 周 |
| ③ 绘图 | 不系统学，遇到再查；ggplot2 的图层语法理解一次即可 | 按需 |

### 5.3 一个真实的例外：如果导师实验室是 R 实验室

【判断】如果课题组的历史代码、内部脚本、师兄师姐的流程全在 R，
那么新人**必须能读懂实验室遗留代码**，否则连复现自己组的前一篇论文都做不到。
**这不改变主线选择**（主线仍是 Python），但 R 的学习深度要从"读懂 vignette"
提到"读懂实验室那套脚本"。这是一个真实的、不可绕过的成本，规划时要明说。

### 5.4 明确的禁止项

**不要用 `rpy2` / `reticulate` 做进程内互操作。**
两套依赖栈混在一个进程里，出问题时既不是 R 的错也不是 Python 的错，
排查成本远超收益，且几乎无法在另一台机器上复现。
**跨语言一律走文件交换**——pseudobulk 的 counts 矩阵存成 CSV 是最稳的桥。
这条与同目录 `scRNAseq_landscape_..._20260910.md` §5 的结论一致。

## §6 会推翻本文的因素，与可证伪的检查点

**一份没有写明"怎样才算错"的预测文档没有价值。** 下表给出可以逐年核对的判据。

| 年份 | 若观察到 | 则本文哪条被推翻 | 应改成 |
| :--- | :---: | :---: | :---: |
| 2027 | 三篇以上高影响力论文用 PyDESeq2 作为唯一差异表达方法且未被要求补 DESeq2 | R 第①块 | 新人可完全不学 R 的差异表达 |
| 2028 | Bioconductor 某次 release 延期，或核心空间包半年无维护 | R 第②块 | 空间统计提前迁往 Python，R 只剩绘图 |
| 2028 | 主流期刊接受基础模型自动注释、无需人工逐簇核对 | §2「注释」行 | 上游语言之争彻底作废，R 的处境反而**改善**（只要有 client 即可） |
| 2029 | scanpy / anndata 出现不兼容的大版本分裂 | §3.1 | Python 的格式优势打折，迁移窗口重新打开 |
| 任意 | 出现一个 Python 原生的、被审稿共识接受的混合效应模型栈 | R 第①块与「实验设计」行 | R 只剩绘图与空间统计两块 |

**另外四个方向性不确定因素**（无法给出年份判据，但会实质影响结论）：

1. **LLM 抹平语言切换成本**——双向作用：既可能加速统一到 Python（因为没人再需要"熟悉"R），
   也可能让 R 存活更久（因为写 R 的边际成本降到接近零，"不熟 R"不再构成理由）。
   **这是我最不确定的一条**，也是唯一可能让本文整体结论失效的因素。
2. **Bioconductor 的维护与资金结构**——核心贡献者偏资深、依赖公共拨款。
   若出问题，R 的空间统计优势会比自然竞争**快得多**地蒸发。
3. **基础模型吃掉上游**——见上表 2028 行，这条反而**延长** R 的寿命。
4. **Python 自己的环境脆弱性**——`anndata` / `scanpy` / `scvi-tools` 的版本冲突是它最大软肋；
   R 的 Bioconductor 同版本齐发在这一点上是工程优势。这不会逆转趋势，但会拖慢它。

## §7 我不确定 / 可以反对的地方

- **五年是一个很长的预测窗口。** 2021 年没有人预测到基础模型会在 2024–2025 主导话语权
  又被 benchmark 打回。同等量级的意外在 2026–2031 之间发生的概率不低。
- **本文的置信度标注是主观的**，没有用任何形式化的预测方法，也没有记录历史预测准确率。
- **"审稿共识"这个概念难以量化。** 我把它当作 R 差异表达那一块的护城河，
  但我没有系统统计过近两年论文里 DE 方法的实际分布——这是本文最弱的一个论证环节。
- **地域差异未考虑。** 判断主要基于英文文献与国际会议生态；
  不同国家、不同学科分支（如临床基因组学）的路径可能显著不同。
- **我的信息截止于 2026-05 加 2026-09-10 那批检索**，中间有四个月盲区（见文首）。
