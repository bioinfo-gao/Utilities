## §0 结论先行

| 用途 | 可信度 | 一句话 |
| :--- | :---: | :---: |
| **细胞类型注释**（给定 marker） | 🟢 **有正经基准支撑** | 与人工注释**高度一致**，且发表在 Nature Methods **【检索】** |
| **通路 / 基因集解读** | 🟡 **高危但可控** | 会产生**上下文相关性低**的通路，必须严格 grounding **【检索】** |
| **marker 判读 / 假设生成** | 🟡 **可用，但只当假设** | 生成快，但**没有独立基准**证明比人做得好 **【判断】** |
| **文献综合 / 机制叙述** | 🔴 **不要信** | 基准显示在"忠实、完整、有文献依据的功能解释"上**持续存在问题** **【检索】** |
| **因果断言**（A 导致 B） | 🔴 **绝不** | 见 §4 |

**一句话**：**LLM 擅长的是"把已有的命名规范套到你的数据上"，
不擅长"从数据里发现新东西"。** **【判断】** 这条区分决定了它所有的正当用法。

## §1 细胞类型注释：目前唯一有硬基准的用法

### 1.1 证据

**【检索】**

- **Nature Methods（2024）**："Assessing GPT-4 for cell type annotation in single-cell RNA-seq analysis"
  —— GPT-4 能**准确地**用 marker 基因信息做细胞类型注释，
  在**数百种组织与细胞类型**上与**人工注释高度一致**；配套 R 包 **`GPTCelltype`**。
- **最佳输入条件（该研究实测）**：**用 top-10 差异基因**、且差异基因由**双侧 Wilcoxon 检验**得出时，
  GPT-4 表现最好。
- **更近的横评**：**7 个主流 LLM + 3 个传统生信工具**，跨 **34 个人/鼠数据集**；
  第一梯队包括 **Kimi-k2、GPT-5、Claude-4.1、Grok-4**。

### 1.2 一个必须说破的方法学问题 **【判断】**

**这些基准的"金标准"是人工注释，而人工注释本身就是"看 marker 查文献"。
LLM 做的是同一件事。** 因此高一致性在相当程度上度量的是
**"它是否符合基于 marker 的命名惯例"**，而不是**"它是否生物学上正确"**。

**⇒ 两条推论**：

1. **对常见、描述充分的细胞类型，LLM 注释是可靠的**——因为惯例本身就是它学到的东西；
2. **对新颖状态、过渡态、疾病特异的异常群体，它会强行套用最接近的已知标签**，
   而且**语气一样自信**。**这正是最需要人来看的地方。**

### 1.3 怎么用（操作规程）

1. **输入用 top-10 DE 基因，检验用双侧 Wilcoxon** —— 直接照搬基准里的最优条件 **【检索】**。
2. **给定候选集**：把可能的细胞类型列表（来自组织学知识）交给它，比开放式提问稳。
3. **一簇一问，不要一次给全部簇** **【判断】**：批量提问会让它倾向于"把标签分散开"以显得合理。
4. **必须交叉验证**：与 `CellTypist` / `SingleR` 这类**监督分类器**对一遍。
   **两者不一致的簇 = 人工必看清单**——这比任何一方单独的输出都有用。
5. **记录不确定性**：要求它对每个簇给出"备选标签 + 为什么排除"。
   **排除理由比结论更能暴露它有没有在编。**
6. **阴性判据**：如果某簇的 marker 里没有任何一个是该细胞类型的经典标志，
   **不要接受这个标签**，无论理由多通顺。

## §2 通路 / 基因集解读：高危区，但有解

### 2.1 失败模式

**【检索】** LLM 做上下文相关的基因集分析（cGSA, contextual Gene Set Analysis）时，
**仍会产生上下文相关性低的通路，原因是幻觉（hallucination）**。
更系统的评测显示：主流通用与生物医学 LLM 在**基因层面推理能力上差异巨大**，
且在生成**忠实、完整、有文献依据**的功能解释上**持续存在问题**。

**【判断】** 这一格的危险性高于注释，原因是：
**通路名称天然"读起来都合理"。** "IL-17 signaling pathway" 出现在一份免疫相关的报告里，
没有任何读者会本能地怀疑——但它可能只是模型从上下文里补出来的。

### 2.2 缓解配方（文献里的做法）

**【检索】** 有效的做法是**强制 grounding**：

> 只把**检索到的簇数据、基因统计量、通路分析结果**作为上下文交给 LLM，
> 并**显式指示：不得使用外部文献、不得做因果断言、不得幻觉**。

再配合**按研究目标优先排序最具代表性的通路**，以及**结构化的 prompt 工程** **【检索】**。

### 2.3 落地成一条规则 **【判断】**

> **LLM 只能给"已经在你的富集结果表里的通路"排序和解释，
> 不能给"表里没有的通路"命名。**

具体做法：把 `clusterProfiler` / GSEA 的输出表**原样贴给它**，要求：
① 只能引用表内条目；② 每条解释必须附上表里的 p 值/基因数；
③ 不得引入表外的通路名；④ 明确写出"这些通路里哪些互为冗余"。
**任何表外出现的通路名 = 幻觉，直接判失败。**

## §3 marker 判读与假设生成

**【判断】**（这一节没有基准可依，全部是我的评估，请按此对待）

**能用的场景**：

- 给一组基因，问"它们共同参与什么过程"——**当作检索加速器**，之后必须回原始数据库核对；
- 给一个反直觉的结果，问"有哪些已知机制可以解释"——**当作假设列表生成器**；
- 问"这个 marker 组合有没有可能是双细胞（doublet）或应激特征"——**这类"提醒"价值高**，
  因为它提示的是**你可能没想到要检查的方向**，而检查本身是廉价的。

**不能用的场景**：

- **任何进入结论的判断**；
- **任何"文献里说……"的转述**——除非你自己去核实了那篇文献。

## §4 绝不能交给 LLM 的三件事

| # | 事项 | 为什么 |
| :--- | :---: | :---: |
| **1** | **因果断言** | LLM 的训练目标里没有任何东西对应"因果"。它产出的因果句式是**语言模式**，不是推断 |
| **2** | **阴性结论**（"没有发现 X"） | "没找到"需要证明"如果有我能找到"。LLM 无法提供这个证明，而它会用同样自信的语气说"未发现" |
| **3** | **文献引用** | 在"忠实、完整、有文献依据"上持续存在问题 **【检索】**。**未经你亲自核实的引用一律视为不存在** |

**【判断】** 第 2 条在单细胞里尤其危险：**"这个通路在处理组没有富集"**
这种句子读起来像结论，实际上可能只是**检验功效不足**（underpowered），
两者在报告里的正确写法完全不同。

## §5 与传统方法的分工

| 任务 | 传统方法 | LLM | 建议 |
| :--- | :---: | :---: | :---: |
| 细胞注释（常见类型） | CellTypist / SingleR（需参考） | GPTCelltype（**无需参考**）**【检索】** | **两者都跑，比对不一致的簇** |
| 细胞注释（无合适参考） | ❌ 无解 | ✅ 可行 | **LLM 的主场**——这是它最有价值的用法 **【判断】** |
| 通路富集 | clusterProfiler / GSEA | ❌ 不能替代 | **富集用传统方法**，LLM 只做表内排序与解释 |
| 通路解读的可读性 | 人工 | ✅ 有效 | 严格 grounding（§2.2） |
| 文献综述 | 人工 | ⚠️ 只当起点 | 每条引用必须自己核实 |

**【判断】** 最有价值的结论是中间那一行：**当你没有合适的参考数据集时，
传统监督注释方法是无解的，而 LLM 可行。** 这是一个真实的能力增量，不是效率优化。

## §6 一个可直接套用的 prompt 结构 **【判断】**

```
角色：你在做单细胞细胞类型注释，输入是一个簇的 top-10 差异基因。
数据：组织 = <组织>，物种 = <物种>，差异基因（双侧 Wilcoxon，按 |logFC| 排序）= <基因列表>
候选集：<组织学上可能的细胞类型列表>

要求：
1. 只能从候选集中选，或明确回答"候选集中没有匹配项"。
2. 给出主标签 + 至多 2 个备选标签。
3. 对每个被排除的备选，写明"排除依据的是哪个基因的存在/缺失"。
4. 不得引用文献，不得使用输入之外的基因。
5. 若 top-10 中没有任何该类型的经典 marker，必须明确说明该结论是弱证据。
```

**为什么这样写** **【判断】**：第 3 条（写排除理由）是关键——
**编造结论容易，编造一致的排除链条难**。这是一个低成本的自曝机制。
