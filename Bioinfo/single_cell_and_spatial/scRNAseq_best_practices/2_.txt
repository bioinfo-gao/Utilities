单细胞 RNA 测序（scRNA-seq）分析在过去 3 年中发生了显著的技术迭代。相比 3 年前，当前的最佳实践更加强调去伪存真（严控假阳性）、数据集成效率以及功能机制分析的标准化。以下是当前（以 R / Seurat v5 + Bioconductor 生态为主线，辅以 Python 优秀工具）的标准单细胞分析完整流程指南。一、 近 3 年单细胞分析的核心变化（最佳实践）双细胞过滤（Doublet Detection）：scDblFinder（R/Bioconductor）凭借最高的准确率和基准测试评分，已全面超越早期的 DoubletFinder 和 Scrublet。多样本差异表达（DE）分析：彻底抛弃以往直接对细胞运行 Wilcoxon 检验的做法（存在严重伪重复导致 $p$ 值过虚），全面采用 Pseudobulk（伪bulk） 结合 DESeq2 / edgeR。数据集成（Integration）：Seurat v5 引入了 Layers 架构与 BPCells，结合 Harmony 或 scVI（通过 Python 交互），极大地提升了大样本量下的计算效率。功能富集与通路转录因子分析：decoupler 成为新一代通路（PROGENy）和转录因子（DoRothEA/MSigDB）活性的标准定量工具。二、 标准单细胞分析七步法详细指南Step 0: 比对与表达矩阵生成（Upstream）推荐工具：Cell Ranger (v8+) 或 STARsolo / salmon-alevin-fry关键参数：确保基因组注释版本最新（如 GRCh38 / mm10 或最新 T2T 参照）。核心输出：表达矩阵（含 barcodes.tsv.gz, features.tsv.gz, matrix.mtx.gz 或 filtered_feature_bc_matrix.h5）。Step 1: 质控与双细胞去除（QC & Doublet Removal）推荐工具：scDblFinder (R) / scater / Seurat质控指标：nCount_RNA（总 UMI 数）& nFeature_RNA（检测基因数）：过滤掉低质量细胞及极高 UMI 的疑似离群细胞。percent.mt（线粒体基因比例）：根据组织类型动态设定阈值（通常 5%–15%）。percent.ribo（核糖体基因比例）与 percent.hb（红细胞血红蛋白基因比例）：评估死细胞与红细胞污染。双细胞过滤：按样本（Sample/Capture Lane）独立运行 scDblFinder，标记并剔除拟合出双细胞得分极高的细胞。交付产物：质控前后 Violin 图、QC 散点图、过滤后的干净 Seurat 对象。Step 2: 标准化、高变基因选取与降维（Normalization & Reduction）推荐工具：Seurat v5 (SCTransform v2 或 LogNormalization)流程策略：推荐使用 SCTransform v2 建模拟合测序深度偏差，自动识别高变基因（HVGs）。运行 PCA 降维，利用 ElbowPlot 结合 JackStraw 确定主成分（PCs）数量（通常 20–30 个 PCs）。交付产物：SCT 矫正后的数据结构、PCA 碎石图（ElbowPlot）、未集成前按样本分布的 UMAP 图。Step 3: 批次效应矫正与数据集成（Integration）推荐工具：Harmony (R) 或 scVI (Python/scvi-tools，通过 seurat-wrappers 调取)流程策略：对不同批次、供体（Donor）或测序板（Batch）进行主成分或隐空间上的矫正。交付产物：集成前与集成后按 Batch/Group 着色的 UMAP 对比图、集成后的近邻图（KNN graph）。Step 4: 聚类与细胞类型注释（Clustering & Annotation）推荐工具：Azimuth / CellTypist (自动注释) + 专家手动 Marker 验证流程策略：构建 SNN 图并运行 Leiden 或 Louvain 聚类算法，设置多重分辨率（Resolution 0.1–1.2）。结合 Azimuth 等预训练模型进行自动化大类推断。提取各 Cluster 的特异性 Marker 基因（FindAllMarkers），结合经典文献与点图（DotPlot）手动修正边界与细分亚群。交付产物：带有清晰细胞类型标签的 UMAP/t-SNE 图、主要亚群 Marker 基因 DotPlot/Heatmap、各组别细胞比例分布条形图（Proportion Barplot）。Step 5: 拟合伪bulk与差异表达/通路分析（Pseudobulk DE & Pathways）推荐工具：DESeq2 / edgeR (用于 Pseudobulk DE) + decoupler / clusterProfiler (用于富集分析)流程策略：将每个生物学重复（Biological Replicate/Donor）内特定细胞亚群的 UMI 进行加总，构建 Pseudobulk 矩阵。使用 DESeq2 拟合负二项分布进行组间差异分析（考虑协变量如性别、年龄等）。使用 decoupler 进行 PROGENy 通路活性和 TF 转录因子活性打分，运行 GO/KEGG/GSEA 分析。交付产物：全基因差异表达表格（Excel/CSV）、火山图（Volcano Plot）、通路富集气泡图。Step 6: 高级下游分析（Downstream Dynamics）推荐工具：CellChat v2 (细胞间通讯分析) / Monocle3 或 scVelo (轨迹与RNA速率分析)流程策略：针对特异细胞类群配体-受体对（L-R pairs）进行信号通路定量，或推算细胞分化路线。交付产物：细胞互作网络图（Circle Plot / Bubble Plot）、轨迹拟时间轴图（Pseudotime UMAP）。三、 流程与交付物对应表以下汇总了每个分析步骤的输入、最佳工具、核心输出与最终产物：阶段
