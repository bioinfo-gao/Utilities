## 1. 系统的三个部件

| 部件 | 是什么 | 分析时要拿到的东西 |
| :--- | :--- | :--- |
| **Cas9**（或 Cas12a 等） | 核酸内切酶，负责切 DNA | 版本（SpCas9 / 高保真变体 / nickase / dCas9）、**怎么递送的** |
| **gRNA**（guide RNA） | 带 **spacer**（通常 20 nt）的向导 RNA，靠碱基互补找到靶点 | **spacer 序列**（含或不含 PAM）——**没有它，靶点与脱靶分析一步都做不了**；另需问**有没有做过可控化修饰**（§4.1） |
| **PAM** | 紧邻靶序列的短基序，SpCas9 是 **NGG** | 从**参考基因组**读出来核对，不要只信客户写的 |

**几何关系（记住这一条就够用）**：
```
         protospacer (20 nt, 与 spacer 互补)          PAM
   5' ── N N N N N N N N N N N N N N N N N ▼ N N N ── NGG ── 3'
                                          ↑
                          切点：距 PAM 第 3 与第 4 个碱基之间
```
- **SpCas9 产生平末端（blunt）双链断裂**，切点在**距 PAM 3 bp** 处。
- 靶点在**负链**时，上述几何在基因组正链坐标上是镜像的 —— **坐标推导必须用已知靶点定标**
  （见 §7 的做法）。

## 2. 断裂之后：细胞怎么修，决定你在数据里看到什么

| 修复途径 | 需要什么 | 结局 | 在 WGS 里的样子 |
| :--- | :--- | :--- | :--- |
| **NHEJ**（非同源末端连接） | 无 | **随机小 indel**，多为 1–20 bp | 读段 CIGAR 里的 I/D；深度不变 |
| **MMEJ / alt-EJ** | 断端两侧有**微同源**（几 bp） | 小缺失，接头处常见 **1–数 bp 微同源** | 同上；接头碱基归属有 1–数 bp 固有不确定性 |
| **HDR**（同源重组） | **donor / HDR template** | 精确敲入 | 出现**非参考序列**；需把 donor 序列作为额外参考 |
| **双切之间片段丢失** | 两条 gRNA | **尺寸确定的缺失** | **嵌合读段**：一段落在左断端、一段落在右断端 |

⚠ **NHEJ 的结局不可预测**：位置可控、尺寸不可控。所以"想删掉某个特定元件"时，
单刀是不可靠的手段 —— 这就是双切存在的理由（§3）。

## 3. 单刀 vs 双刀（dual cut）

| | **单刀** | **双刀（两条 gRNA）** |
| :--- | :--- | :--- |
| 结局 | 随机小 indel，尺寸不可预测 | **两刀之间整段切除**，尺寸事先设计好 |
| 能不能定点删掉某个元件 | 只能指望移码碰巧奏效 | **能**（如删掉起始密码子、某个 exon、某段调控元件） |
| 凝胶能否直接看出来 | 通常不能（差几 bp） | **能** —— 产物短一截 |
| 等位基因可分辨性 | 差 | **好**：未编辑给长产物、缺失给短产物，两条带并存 = 单等位 |
| 数据里的证据 | indel 读段 | **跨接头的嵌合读段** |

**双刀间距是个设计选择**：太短（<100 bp）凝胶分辨不出、太长（>1–2 kb）切除效率下降。
常见 150–500 bp。

### 3.1 双刀可能的其他结局（不要只找缺失）

| 结局 | 说明 | 证据形态 |
| :--- | :--- | :--- |
| **片段缺失**（最常见） | 中间段丢失，两端直连 | 嵌合读段：左断端 ┃ 右断端 |
| **片段倒位** | 中间段原地翻转后接回 | 嵌合读段的一端是**反向互补** |
| 片段保留但两端各有 indel | 两刀各自独立 NHEJ | 两处小 indel，无嵌合读段 |
| 一刀切、另一刀没切 | 单刀结局 | 只在一个切点见到 indel |

## 4. 等位基因层面 —— **最容易和"细胞"混淆的一层**

二倍体细胞每个位点有**两条等位基因（allele）**。编辑结局要分两个维度描述：

| 维度 | 取值 | 判据 |
| :--- | :--- | :--- |
| **等位基因层面** | 单等位（heterozygous）/ 双等位（homozygous）/ 两条各自不同（compound） | 变异读段占比：~50% / ~100% |
| **细胞层面** | 单克隆（每个细胞相同）/ 混合群体（细胞之间不同） | 需要克隆化信息，**测序数据本身通常判不出** |

⚠ **"不是全部拷贝都带缺失" 这句话有歧义，禁止使用。**
在**单克隆**系里，单等位缺失 = **每个细胞都带**，只是两条等位基因里的一条；
数据里同时看到完整序列的读段，那是**另一条等位基因**，不是"没被编辑的细胞"。
正确写法见 §8 的术语表。

**低深度下的陷阱**：等位基因占比要靠读段计数估计，而计数服从二项分布。
真实 50% 时，**6 条读段里观察到 ≤2 条变异读段的概率是 34%**。
⇒ 深度不足时**不要给百分比**，只说"单等位 / 双等位"。

### 4.1 时空可控的 CRISPR：caged gRNA（笼锁 gRNA）与光激活

**要解决的问题**：常规 CRISPR 一旦递送进细胞就**持续切割** —— 无法控制"何时切""切哪些细胞"，
更谈不上"只切一条等位基因"；而且核酸酶长时间保持活性会**抬高脱靶**。

**caged gRNA 的做法**：在 gRNA 的关键位置（多在 spacer / seed 区）接上**光敏保护基团**
（photo-labile caging group，如硝基苄类衍生物）。带着基团时无法与靶 DNA 正常配对
⇒ **不照光就不切**。用特定波长的光（常见近 UV ~365 nm；新化学可用可见光或双光子）
把保护基团切掉，gRNA 恢复活性 ⇒ 从那一刻起开始切割。

由此得到三个维度的控制：**时间**（何时开始）、**空间**（只照到的细胞/区域）、
以及配合聚焦照明时的**亚细胞乃至单等位**选择性。

**同类思路**（遇到时按同一套逻辑理解）：photoactivatable Cas9（paCas9）、
小分子诱导系统（4-OHT / rapamycin 诱导二聚化）、anti-CRISPR 蛋白（Acr）抑制。

**单等位编辑怎么做到的**：二倍体细胞里两条等位基因在核内占据**不同的染色体疆域**
（chromosome territory）。用聚焦光只解笼其中一处 ⇒ **只有那一条被切**，
另一条保持未编辑 ⇒ 预期结局是**单等位缺失**（§4）。

**配套的活细胞报告基因（见到它基本能反推实验意图）**：
**53BP1** 会在双链断裂处快速聚集成 **focus**。把 53BP1 的
**FFR = Focus-Forming Region**（常用片段约 aa1220–1716）与荧光蛋白融合，
即为广泛使用的 **mCherry-BP1-2** 报告子 —— 在活细胞里用一个红色 focus 标出**断裂发生在哪**。
⇒ **载体里带 `53BP1-FFR` / `BP1-2`，说明实验是在显微镜下实时观察 DSB，而不是单纯做编辑。**

**⚠ 代价与对数据分析的影响（必须写进 Limitations）**：

| 现象 | 后果 | 分析时怎么处理 |
| :--- | :--- | :--- |
| **leakage（本底切割）** | 照光前并非绝对零活性 | "未照光对照"**不等于**零暴露 |
| **解笼不完全** | 实际编辑效率低于自由 gRNA | 阴性结论要更谨慎；低深度下证据更薄 |
| **UV 光毒性** | 可能引入与 CRISPR 无关的 DNA 损伤 | 断点/变异不可一概归因于编辑 |
| **只照了一条等位基因** | 变异读段占比 **~50%** 而非 ~100% | 别把 ~50% 误读成"只有一半细胞被编辑"（§4 的歧义） |
| 对照"只是没照光" | 它**仍然带着 Cas9 与 gRNA** | **不是 CRISPR-naive 基线** ⇒ 不能做差集（§5） |

## 5. 脱靶（off-target）

**成因**：spacer 允许一定程度的错配仍能结合并切割。

| 因素 | 说明 | 分析要做的事 |
| :--- | :--- | :--- |
| **错配数** | 通常 ≤4 个错配的位点值得列为候选；靠近 PAM 的错配更致命 | 全基因组枚举 |
| **PAM 变体** | NGG 最强；**NAG** 等非经典 PAM 活性弱但存在 | 主表 NGG、次表 NAG **分开报** |
| **bulge**（凸起） | gRNA 或 DNA 侧多出 1 个碱基 | `seqkit locate` 等只做 mismatch **做不到**；需 Cas-OFFinder |
| **染色质可及性** | 序列匹配但不开放的位点未必被切 | 序列枚举只给**候选**，不给事件 |

⚠ **双刀实验的脱靶重点不一样**：最危险的不是"某条 gRNA 单独有个近似位点"，
而是**两条 gRNA 在同一处都有近似位点、且间距与靶点相近** —— 那里可能发生
和靶点一样的片段切除。**这类位点必须单独枚举**（同源基因、假基因家族是高发区）。

**⚠ 对照的前提**：拿"编辑样本减对照"做差集，**前提是对照没接触过 CRISPR**。
若对照自身带 Cas9、或同样做过处理，差集会把共有的脱靶一起减掉 ⇒ **必须两样本并列报**。

## 6. 递送方式 —— 决定要不要额外筛查外源序列

| 方式 | 是否留下外源 DNA | 分析后果 |
| :--- | :--- | :--- |
| **RNP**（蛋白 + gRNA 复合物） | 否 | 无需筛查；Cas9 暴露时间短，脱靶通常较少 |
| **mRNA / 瞬转质粒** | 通常不整合，但**可能随机整合** | 建议筛查 |
| **质粒转染** | **可能连骨架一起整合** | **必须**筛查骨架（AmpR / ori） |
| **逆转录病毒 / 慢病毒** | **稳定整合**，两 LTR 之间的序列进入基因组 | **必须**筛查整合位点；骨架**不应**整合，若见到需解释 |

**筛查载体时的两个必踩陷阱：**
1. **载体里的人源序列**（如人 cDNA 融合报告基因）会比对到人基因组、**不进 unmapped 池**
   ⇒ 只用未比对读段筛查会在这些区段得到 0 覆盖，看起来像"没有该载体"。
   **必做**：把载体按读长瓦片化回贴人基因组，可映射的位置**屏蔽掉**再算覆盖。
2. **载体是环状、参考是线性** ⇒ 跨首尾接口的读段必被 clip，那些 clip 是**载体序列**不是基因组序列。
   ⇒ 找整合接头要用**基因组端 clip 回贴载体**，不要反过来。

**拷贝数估计**：只用**载体唯一**的元件（如 Cas9、EGFP、mCherry）；
两个载体共有的元件（LTR、抗性基因、骨架）会被 MAPQ 过滤压低，**低值反映可映射性而非含量**。
`拷贝数 ≈ 2 × 元件平均深度 ÷ 全基因组平均深度`（二倍体里 1 份 ⇒ 1.00）。

## 7. 编辑产物在测序数据里的形态 —— 判读速查

| 你要找的 | 读段形态 | 比对器会替你发现吗 |
| :--- | :--- | :--- |
| 小 indel | CIGAR 里的 I/D | 会 |
| **双切片段缺失** | 嵌合读段，两段**都在基因组**上、相距 = 设计尺寸 | **会** —— 产出 supplementary alignment 并写 `SA:Z:` 标签 |
| **载体整合接头** | 一段在基因组、另一段**比不上基因组** | **不会** —— 只留一个 soft-clip、**没有 SA 标签**；必须把载体作为额外参考 |
| 倒位 | 嵌合读段一端为反向互补 | 会（SA 标签的链方向相反） |
| 大片段纯合缺失 | 该区**零覆盖** | 深度分析可见 |
| 大片段杂合缺失 | 深度约减半 | 需要足够深度才分辨得出 |

**⇒ 「有没有 `SA:Z:` 标签」是区分"两段都在基因组"与"另一段是外源序列"的现成判据。**

**坐标推导必须定标**：把已知靶点放进自己的流程，**要求流程能还原出客户给的切点坐标**，
不通过就不许继续（写成断言）。链方向、1-based/0-based、PAM 在哪一侧，
这些地方错一个就全盘错，而且错得很像对的。

## 8. 术语与写作口径（内外文档统一）

| 概念 | **必须写成** | **禁止裸用** |
| :--- | :--- | :--- |
| 同一细胞里同一位点的两份 DNA | **allele（等位基因）** | `copies` |
| 群体里的细胞个体 | **cell（细胞）** | `copies` |
| 每个基因组整合了几份载体 | **vector copy number（载体拷贝数）** | `copies` |
| 只在某样本检出 | **sample-specific（样本特异）** | "编辑造成"（除非有直接证据） |
| 序列上像的位置 | **candidate（候选）** | "检出的脱靶" |
| 有读段支持的实际改变 | **event（事件）** | —— |
| 一个整合有两个接头 | **junction（接头）** | 把接头数说成"整合位点数" |
| 深度 | 写明口径：原始 / 去重后 / **去重+配对重叠校正** | 裸写"深度" |
| 笼锁 gRNA | **caged gRNA**（光敏保护基团，照光才有活性，§4.1） | 把样本名里的 `cg` 想当然读成 "CRISPR guide" |
| 53BP1 报告子 | **53BP1-FFR = Focus-Forming Region**，融合荧光蛋白后标记 DSB（§4.1） | 当成被编辑的靶基因 |
| 读段计数 | 写明**按读段名去重** | 把 BAM 行数当读段数 |

**阴性结论的写法**：写"未检出 X"时**必须同时给出该处的证据量**，
并能回答"若 X 真的存在，期望看到几条读段"。**未检出 ≠ 不存在。**

## 9. 接项目时问客户的最小清单

1. **gRNA spacer 序列（含 PAM）**、靶基因/位点、**预期切点坐标**（并注明参考基因组版本）
2. 双切的话：**两条 spacer + 间距**、预期结局（缺失 / 倒位）
3. **单克隆还是混合群体**；对照是不是同一亲本、传代差多少
4. **递送方式**（RNP / 质粒 / 病毒）+ **每个构建体的完整序列（含骨架）**
5. **对照是否也接触过 CRISPR / 是否带 Cas9** ← 决定能不能做差集
6. **有没有用可控化系统**（caged gRNA / 光控 / 小分子诱导）？如何激活、激活了哪些细胞或哪条等位基因？
   ← 决定预期的变异读段占比是 ~50% 还是 ~100%，也决定"对照"到底对照了什么
7. 样本命名里的缩写各指什么

⚠ 前 6 项**缺任何一项都会让相应分析无法进行**，且**事后补不回来**。
