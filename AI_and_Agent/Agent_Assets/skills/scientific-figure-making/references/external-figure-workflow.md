# 外部图件生成与修订工作流

适用：机制示意图、graphical abstract、实验/分析流程图，以及外部画布或异步作图服务。R/Python 数据图仍走现有脚本与图件验证流程。此处不授予上传、付费或安装权限，也不要求使用某一厂商。

## 先决定图件承担什么证据

- 数据图：坐标、数值、统计量、缺失值和类别顺序由可追溯的数据与脚本决定。外部工具可辅助排版；如要让其直接生成统计数据图，先通过下文数据图验收。
- 示意图：先用文字明确实体、箭头方向、作用关系与证据层级，再生成视觉表达。假设关系与实测关系必须在图例或线型中区分，不让生成工具补出未经支持的机制。
- 流程图：先列输入、阶段、分支条件和输出，再排版。用已确认的流程作为来源，不从画出的箭头反推分析设计。

## 小范围修改与来源记录

标签、颜色或单个区域有问题时，优先修改对应对象/区域；R/Python 图修改源脚本，外部画布使用实际支持的局部编辑。布局涉及全图时可整体调整。局部修改后检查受影响区域及相邻关系，避免无关元素漂移。

在项目已有的图件记录中保留输入路径/版本、作图脚本或生成指令、输出版本及导出设置；使用远程服务时补充 provider、project/workspace、job/source/version ID、首次提交时间、实际返回的消耗（若有）。只保存实际返回的标识和无凭证链接，不存签名下载链接、授权跳转 token 或密钥。没有既有图件记录且涉及远程任务时，可建一份 machine-readable manifest，避免重复维护相同信息。

编辑目标以用户明确指定的文件/版本为准；用户指向当前选中画布对象时，用可用的界面状态确认对象。选择状态不可读取且目标不明时询问，不默认修改“最新生成”。修订前旧版归档沿用主规则，新旧版本及对应脚本/指令可对照。

## 异步任务与失败恢复

提交后保存原 job ID；服务支持 idempotency key 时，同一次预期操作重试沿用同一 key。查询超时、预览失败、网页未刷新均不代表生成失败：先查询同一任务，区分 processing、业务 failed、鉴权/传输错误和展示错误。遵从服务实际重试间隔，不为修复显示问题再次生成。

仅在确认原任务终态失败、且重试仍在用户授权及费用范围内时重新提交。状态无法确认时保留原任务上下文并报告，不以新 key 绕过未知状态。图件完成、可打开、文件已下载、已检查质量分别记录，不互相代替；同版本已通过的检查可复用，新版本只复查受影响部分及必要的全图一致性。

## 配色与正式采用验收

类别颜色从主 skill 指向的 canonical `palettes.csv` 和 `select_palette()` 取得，明确传入“类别—HEX”映射；不从参考 JPG 重新抄色，也不让工具自由补色。既有跨 panel 语义、白底可读性、黑色 median 及连续色标规则继续适用。提示中写了颜色不代表导出执行正确：检查实色区域/矢量填色，避开抗锯齿边缘；若为生成式纹理，不能据提示声称精确色值已通过。

首次采用某外部工具时，以公开或模拟内容做与用途匹配的小型验收，记录实际结果与限制：

| 用途 | 验收证据 | 未通过时的处理 |
| :--- | :---: | :---: |
| 示意图/流程图 | 实体和箭头关系正确，文字可读，无凭空机制；颜色、局部编辑、版本保留符合要求 | 修正或更换工具，不标作已验收 |
| 需要后续编辑的图件 | 实际导出/重新打开后所需文字、对象仍可编辑 | 仅保留为草图或按实际格式交付，不宣称可编辑矢量 |
| 正式 PDF/SVG 图件 | 实际格式可读、字体/裁切/分辨率符合用途；区分矢量对象与嵌入位图 | 不把改扩展名或位图套 SVG 容器当矢量化 |
| 直接生成统计数据图 | 用含已知坐标、NA、0、类别顺序的测试数据核对结果；可导出生成源码或等价可审查绘图规格，并由该来源复现 | 不采用为正式数据图生成器，继续 R/Python |

客户未公开数据进入第三方服务前须有明确授权；可先使用去标识且获授权的必要汇总数据。服务额度、导出格式和可编辑性依实际账户与返回结果确认，仓库文档不证明线上能力。
