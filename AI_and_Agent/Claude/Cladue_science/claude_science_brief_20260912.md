## 一句话判决

> **不纳入常规工作流；保留为偶发的「外部扰动源」。**
> **它值得偶尔用来提问，不值得用来干活；而它提过的问题，应该变成我们自己的常规检查。**

## 是什么

一个本地浏览器应用（装在同一台服务器，端口 8000 + 8001，经 SSH 隧道访问），
把「探索性数据分析」打包成 **沙箱 + 60 余个科学数据库 connector + 带 provenance 的 artifact**。

| | Claude Code CLI | Claude Science |
| :--- | :---: | :---: |
| 形态 | 终端命令行 agent | 浏览器应用，**没有「命令行提交任务」这回事** |
| 模型 | 同一批通用模型 | **同一批通用模型**（官方明确：不是更强的生物学模型） |
| 配额 | ——— **共用同一个 seat、同一份周配额** ——— |||
| 擅长 | 改文件、跑命令、管线编排、长任务、交付 | 一次性的探索：出图、查库、算一算、写 Methods |

**⇒ 分界线一句话：能重复跑在新样本上的 = pipeline = Claude Code；一次性的探索 = Claude Science。
全部价值在 workflow，不在模型。**

## 它真正的价值：**盲区和我们不重叠**

**最硬的一条证据**：它触发了一个**已交付客户产物**里的缺陷，而那份交付走完过我们全套自审 ——
proj16 标 `absent`（判为罕见、进候选名单）的位点中 **70–72% 其实在同一个 VCF 的 VEP CSQ 里就有
gnomAD v4.1 频率**，其中 **4,428 条是 AF > 0.01 的常见多态**，约占候选名单一半。
**零报错、退出码 0、表格看起来完全正常**，是 30 个位点的盲测把它顶出来的。
（proj36 已全量核实；**用户 2026-09-12 裁定不通知客户，全部工作属内部研究。**）

**双向都发生过，这才叫盲区不重叠：**

| 方向 | 抓到了什么 |
| :--- | :---: |
| 它 → 我们 | caption 选取规则错（写 top40、实画 balanced 20/20，8 个基因不在字面 top40）；gnomAD 注释源整个用错 |
| 我们 → 它 | 阈值被 `%.2f` 印成 0.26；`--no_timestamp` 实现成语义相反的 `--keep_timestamp` **且从不回报** |

**⇒ 它的价值不在「多一双手」，在「多一套独立实现」。换一个同样由我操作的工具，不会有这个效果。**

它最强的能力**不是算得快**，是：把主张和证据绑在一起、**自己给自己设反证**
（接受「gnomAD 查不到」之前先用已知阳性验证查询语法）、主动说「这条证据无效」、工具失败如实报告。

## 成本：增大了，而且增的地方不是它

| 日期 | Claude Code | Claude Science | CS 占比 |
| :--- | :---: | :---: | :---: |
| 部署前 12 天日均 | **$61.87** | — | — |
| 09-10 部署当日 | $138.29 | $32.87 | 19.2% |
| 09-11 两轮测试 | $110.43 | $9.40 | 7.8% |
| 09-12 追查 | $105.24 | **$0** | 0% |
| **三天合计** | **$353.96** | **$42.27** | **10.7%** |

**三条要记住的：**

1. 日均从 **$61.87 涨到约 $132**，**消耗确实增大了** —— 但涨的几乎全在 Claude Code 这边（部署它、**复核它的产出**、追查它提出的问题）。
2. **验证它的产出，比它自己跑一遍贵一个数量级。**「把额度挪过去」这个动作不存在，只有「额外花一笔」。
3. **它不会在后台偷偷烧额度** —— daemon 常驻 2 天，09-12 花费 $0。**常驻不花钱，花钱的只有会话。**

**⇒ 它的花费不该和 Claude Code 比单价，该和「一次返工 / 一次客户发现问题」的代价比。**

## 什么时候用（**两条必须同时满足**）

1. **错了的代价高** —— 已交付、要发客户、或错了要整条重跑；
2. **有真值可对，或能构造** —— 有旧管线结果、有设计已知的阳性对照、有公开数据库可查。

**用法只有一种站得住：双盲平行复算。** 同一份原始输入，**剥掉我们已有的答案**给它，
让它独立产出，再用脚本做差异清单。**不要让它 review 我们的答案** —— 把答案给它看，
就毁掉了它唯一值钱的东西：独立性。

**六步法与可粘贴的任务指令模板见详细版 §6.3。三个最容易白跑的坑：**

| 坑 | 后果 |
| :--- | :---: |
| 输入里带着答案（VCF 的 INFO 本身就是底牌） | **必然假通过** |
| 随机抽样而不分层 | 抽 30 个期望命中 0.02 个，**整轮白跑** |
| 核对脚本自己没验收 | 我的核对器第一版把 6 条「它说查不到」误判成「编造」，**假阳性正好落在一票否决那条上** |

## 边界（不变）

| 不进的 | 为什么 |
| :--- | :---: |
| 管线、调度、长任务 | kernel 闲置 30 min 回收、远程作业默认 30 min 超时，接不住 14.5 h 级并跑 |
| 交付目录、客户面文字 | **我们的 hook 一条都不生效**（破坏性命令闸门、冻结交付物闸门、回复自检） |
| 当唯一验收者 | reviewer **只查叙述层**，官方明确不重跑分析；我们吃大亏的错全在计算层 |
| 依赖会话内状态 | daemon 会自己重启（崩溃 / 自动升级）⇒ **一律落盘** |

**⛔ 两条硬的**：
① **AlphaFold2 / Boltz-2 默认把蛋白序列发到公共 ColabFold 服务器**（从本机直发，不经 Anthropic）——
客户未公开序列必须自带 MSA 或关掉该 skill。
② **远程作业跑在沙箱之外，以你的账号身份**，能读写你账号能读写的一切。

**边界纪律实测：守住了。** 全程对交付目录只读，事后 `find -newermt` **零命中**，430 个文件一字节没动。

## 对不太懂生信的人作用更大吗？——**方向相反**

它的亮点**全是专家级动作**（等位基因等价匹配、先验证查询语法再接受阴性、比深度前先归一化、
排除 MAPQ=0 的 supplementary 臂）——**这些恰恰是新手评估不了的**；
而它做错的三处**全部靠「有人去查」才暴露**。

**⇒ 对不能验证的人，它提高的是产量和表面可信度，不是可靠性，还提高了「错得像对的」概率。
它的价值全部在差异清单里，而读差异清单需要专家。**

## 本机三条必须自己补的缺口

1. **hooks 一件都过不去** ⇒ `claude-science-guardrails` skill 顶上（已落盘 `~/.claude/skills/`），
   并限定它**只在探索目录工作**。
2. **skills 不自动共享** ⇒ 需 Settings > Skills 的 Import/Upload，**不要往它的内部目录塞文件**（升级会覆盖）。
3. **L0 `CLAUDE.md` 没有等价物** ⇒「只准备不发送」「不建议长读长」「测序参数是我方决定」不搬过去就不受约束。
