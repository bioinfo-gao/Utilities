# 科学术语的中英取舍 —— 简要规范

- **创建**：2026-08-26（起因：把 `reporter` 写成「报告子」、把 `junction` 写成「接头」被指出）
- **适用**：内部研究文档、客户交付物、邮件、图件标签、代码与文件名 —— 全部。
- **与 `~/.claude/CLAUDE.md` 的关系**：CLAUDE.md「术语中英取舍 —— 四分法」一节是**生效副本**
  （每次会话自动进上下文）；**本文件是较完整的版本**。**两边必须同步**，改一边要改另一边。

---

## 1. 一句话规则

> **默认用英文原文。要译成中文，得先证明它属于第 2 节的前三类之一。**

理由不是"英文更高级"，而是读者侧的事实：**高级专家在文献中首先看到的就是英文，不需要翻译**；
而非标准译名不是帮忙，是**制造理解障碍**。

**⚠ 但这只是第一条轴。第二条轴是：这个词在本文里是否只有一个所指？**
保留英文原文**不等于**消除歧义 —— `copies` 就是全程用英文、照样把客户引到反面的实例（§3.1）。
⇒ **两条都要过**：① 用哪种语言写；② 这个词是不是只指一件事。

---

## 2. 四分法：先归类，再决定怎么写

| 类别 | 处理 | 实例 | 为什么 |
| :--- | :---: | :--- | :--- |
| **A. 中文明显更好** | **只用中文** | 代数学、特征值、特征向量 | `algebra` 源自阿拉伯语 *al-jabr*、`eigen-` 是未翻译的德语 —— **对英语读者本身就不透明**；中文直接说出"以符号代数""特征"，更透明 |
| **B. 英文明显更好** | **只用英文** | socket、rational number | `套接字` 是生造；**`有理数` 更糟** —— `rational` 来自 *ratio*（可表示为两整数之比），经日译取 `理 = reason`，于是 `无理数` 读起来像"不讲理的数"，**把定义本身遮掉了** |
| **C. 两者都好、侧重互补** | **中英并存** | 光敏保护基团（caging group） | 中文说清"**是什么**"（光敏、保护性、可被切除），英文是**本领域检索与沟通的术语** |
| **D. 英文新词、无标准中文译名**（大部分科学术语属此类） | **默认只用英文** | reporter、junction、microhomology、provirus、soft-clip、supplementary alignment、chimeric read | 专家先在文献里看到英文；自造译名会引入原文没有的歧义 |

**判断顺序**：先问 D（这词有公认中文译名吗？没有 ⇒ 用英文，结束）→ 再问 B（现有译名是生造或误读吗？）
→ 再问 A（中文是否比英文更透明？）→ 最后问 C（两边都准确且互补吗？）。

## 3. 三种失效 —— 前两种是真实事故，逐条复盘

### 3.1 英文原词**自身一词多义** ⇒ **保留英文也不够**

**实例：`copies`（2026-08-26，客户来信）。** 客户读完我方邮件后写道：

> *"Just to clarify, when you say that the large deletion does not occur in all copies, does that
> mean that there are also some copies in which the large deletion did not occur? Because the large
> deletion occurred in a single allele, I would expect the large deletion to be present in all copies."*

**客户完全正确，而且我方那句话确实自相矛盾。** 根源：`copies` 在那个项目里同时承担**三个概念** ——

| 想说的 | 应写成 | 该项目的值 |
| :--- | :--- | :--- |
| 同一细胞里同一位点的两份 DNA | **allele** | 一条缺失、一条完整 |
| 群体里的细胞个体 | **cell** | 单克隆 ⇒ 细胞之间应当一致 |
| 每个基因组整合了几份载体 | **vector copy number** | 各约 1 份 |

我方写的是「not in all **copies**」，本意是 allele；客户按常识读成 cell ——
而在**单克隆**系里"单等位缺失"恰恰等于**每个细胞都带**，所以按 cell 读，那句话在说
"有一部分细胞没被编辑"，与单等位缺失矛盾。**每个数字都对，句子却把人引到反面。**

**⇒ 教训：保留英文原文只解决"翻译"这一半。** 另一半是：
**这个词在本项目里是否只有一个所指？** 不是 ⇒ 一律写全限定形式，**裸用视为错误**。

### 3.2 译名**撞上中文既有词** ⇒ 不译就没事，译了才出事

**实例：`junction` → 「接头」（同期，两份文档共 45 处）。**
**在测序语境里「接头」通常指 adapter**（接头去除 = adapter trimming）——
中文这个词在本领域**已经有主**。于是同一个词在同一篇文档里指两个东西，
而英文原文 `junction` 与 `adapter` 从不混淆。**是翻译动作本身制造了歧义。**

### 3.3 译名**源于误读** ⇒ 读者按字面理解得到错误概念

**实例：`rational number` → 「有理数」。** `rational` 来自 *ratio*（可表示为两整数之比），
经日译取了 `理 = reason`，于是 `无理数` 读起来像"不讲理的数"，**把定义本身遮掉了**。

---

⇒ **两条操作结论：**
1. **一旦想造译名，先证明它不属于 3.2 / 3.3。默认不造。**
2. **即使全用英文，也要再过一遍 3.1**：把本项目里承担多个概念的词列成表，
   写进文档第 1 节，之后正文只许用限定形式。**这一步发现不了靠自己 —— 靠读者提问**
   （`copies` 就是客户问出来的）。**每一次"这是什么意思"，都回填成词表一行 + 一条断言。**

## 4. 分场合的取舍

| 场合 | 规则 |
| :--- | :--- |
| **内部研究文档** | 中文叙述 + **术语按第 2 节处理**（不是"全部译成中文"） |
| **客户交付物（报告、结果表）** | **全英文**，不涉及取舍 |
| **客户邮件** | 全英文；术语用客户自己用过的说法（对方的措辞优先于我们的偏好） |
| **图件的轴标签 / 图例** | **英文**（图常被直接放进英文报告或投影） |
| **目录名** | **仅 ASCII 英文**，无例外（跨工具/系统可移植） |
| **文件名** | 英文为默认；中文只在明显更自然时用 |
| **变量名 / 列名 / 字段名** | **仅英文**，且与文中术语一致（`junction_reads` 对应正文的 junction） |

## 5. 落地：写成断言，不靠自觉

- **反向断言**：自造译名清单出现即报错。
- **正向断言**：该中英并存的（C 类）必须并存，防止日后批量替换把中文那半剥掉。
- **批量替换后必须做两件事**：
  1. **查重复 artifact** —— "载体–基因组接头 junction" 替换后会变成 "…junction junction"；
  2. **中英相邻处补空格**，便于扫读。
- **断言本身要用注入式阳性对照验证会触发**，否则又是一个恒过的检查。

范例实现：`projects_2026M7/31_.../scripts/with_client_info_20260825/17_check_internal_doc.py` 的 B2 类。

## 6. 本领域的既定处理（遇到新词往下加）

| 只用英文 | 只用中文 | 中英并存 |
| :--- | :--- | :--- |
| reporter、junction、microhomology、provirus、soft-clip、supplementary alignment、secondary alignment、chimeric read、spacer、protospacer、PAM、indel、bulge、allele frequency、breakpoint cluster | 等位基因、断点、缺失、倒位、拷贝数、基因组、染色体、单克隆、读段、深度、覆盖度、比对 | 光敏保护基团（caging group） |

⚠ **`接头` 已列为禁用**（撞 adapter）；`报告子`、`报告基因` 已列为禁用（自造，用 reporter）。

**另设一栏：本身一词多义、必须写全限定形式的词（裸用即错，见 §3.1）**

| 裸用（禁止） | 必须写成 | 备注 |
| :--- | :--- | :--- |
| `copies` / 拷贝 | **allele** / **cell** / **vector copy number** | 客户实际因此误读过 |
| 深度 | 原始产出 / 去重后 / **去重+配对重叠校正** / 局部读段计数 | 同一项目里四个数差到两倍 |
| reads / 读段 | **按读段名去重的读段** / **alignment record** | 一条 chimeric read 在 BAM 里是多行 |
| 特异 / specific | **sample-specific**（只表示"只在该样本检出"，**不含因果**） | 对照若也接触过处理，特异 ≠ 造成 |
| 整合位点 | **junction**（一个位点两个 junction）/ **integration site** | 数量不同，别互相替代 |
