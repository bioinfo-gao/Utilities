# 第 1、3 图配色样图

6 张样图 + 1 张完整色卡，各有 PNG/PDF。所有数据为固定随机种子的模拟数据，不代表实验结果。

- 两套方案使用完全相同的数据与版式，便于比较配色。
- 色相表示 Category，浅色表示 Control，深色表示 Treatment。折线另以线型和点形辅助区分。
- 原色依据 1.jpg 与 3.jpg 标注的 HEX 值转录；深浅色由 make_examples.py 的 HLS 规则生成，是待选择候选，不是期刊官方色板。色值唯一记录在 palette_pairs.csv。
- 示例各选 4 个色相，避免将所有衍生色同时挤入一图；全部原色及其深浅版本见 00_palette_pairs。
- 箱线图每组显示 18 个模拟点，median 为黑色；柱状图为 mean ± SEM。
- 未验证色觉缺陷模拟或灰度辨识度。浅色折线在白底上的辨识度应结合实际缩印尺寸判断。

复现：`python3 make_examples.py`。输出目录已存在同名文件时请先归档，勿直接重跑覆盖。
