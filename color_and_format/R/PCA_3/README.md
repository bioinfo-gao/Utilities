## 这一轮定下的通则

1. **散点按尺寸分两类**：小点（默认小圆点）按**线状**取色；
   **有明确形状的大点不用纯黑，用 `#4D4D4D`** —— 两次独立确认。
   不是可见度问题（纯黑对白底 21.0 全场最高），是观感：大面积实心黑点死板刺眼，
   且易与点的黑描边、黑标签文字糊成一团。
2. **候选之间只差一个组的颜色时，用「该簇放大」对照，不要用整图并排。**
   两张 18 点 PCA 并排、只差 3 个点，看不出来是呈现方式的错，不是配色的错。
3. **「加深」≠「拉齐深浅」。** 后者会抹掉靠亮度差撑开的可分度：
   Default_A 紫系三色色相只差约 35°，全靠 L=76.8/61.5/87.0 拉开，拉齐后塌到 0.089。
4. **缩略 grid 系统性低估配色**，判读一律以单张大图为准。

## 数值指标在哪些地方失效（本轮实测，四类）

**这是本轮最重要的产出 —— 这些写不成断言，只能靠眼睛。**

| 失效类型 | 实例 | 方向 |
| :--- | :--- | :--- |
| 低彩度"闷"色调之间 | 棕 `#B87542` vs 浊粉 `#E9A6A1`（0.266）；浊金 `#C6B500` vs 浊粉 `#CC92B1`（**0.411，全套第二高**） | **高估**可分度 |
| 暗色之间 | 蓝 `#1F78B4` vs 深绿 `#006D2C`（0.315，全局 min 0.221 全场最高） | **高估** |
| 低饱和彩色 vs 中性灰 | `#6E7B8B` vs `#ABABAB`（0.184） | **低估**（色相差眼睛看得出） |
| 淡色的死活取决于簇内搭档 | 同一个 `#FFED6F`（对白底 1.19）在方案3 可用、在原方案1 不可用 | 单色指标不足以判断 |

**单个浅色不致命，六个全浅才致命。**

## 运行

```bash

```

**本文件不手写任何色值** —— 一律由 `palette_priority.R` 的正式入口取色再套用已定案的逐位替换，
改了池子这里会自动跟着变。

加深后色相漂移 ≤2°、全局最小色距 ≥0.10、中文渲染失败即 `stop`。
