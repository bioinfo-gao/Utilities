## 意见1 的两种加深模式 —— 结果不一样，别混

用户只说「加深」。我第一版**顺手把深浅也拉齐了**（统一到对比度 4.5），结果坏事：

原版这套色的可分度**有相当一部分来自深浅不同，而不是色相不同** ——
紫系 `#BEBADA` / `#BC80BD` / `#FCCDE5` 色相只差约 35°，靠 L = 76.8 / 61.5 / 87.0 拉开。
把 L 拉平，这部分可分度就没了：

| 模式 | 全局最小色距 | 对白底 |
| :--- | :---: | :--- |
| 原版 | 0.127 | 1.19–3.02（**深浅不均**） |
| **等量降 L −30（当前默认）** | **0.126** | 2.87–8.83 |
| 拉齐到对比度 4.5 | **0.089 ❌ 低于 0.10 门槛** | 4.48–4.52 |

塌陷的两对：`#9F6585` vs `#A759A9` = 0.089、`#77729A` vs `#9F6585` = 0.094。

**教训：「加深」和「拉齐深浅」是两件事，后者是我自作主张加的，而且有害。**
两种模式都出图 —— 见 `CAND_01_A_fills_darkness.pdf`。

### 意见1b：等量-20 + 位4 改 cyan（**当前默认**）

看过 `CAND_01` 后用户判：**等量-20 总体最佳，但右下 6 点仍分不清，其中一组改 cyan。**

右下 = cDC2 簇 = 位3 `#C6B500`（浊金）+ 位4 `#CC92B1`（浊粉）。
**这两者 RGB 距离 0.411，是全套里数一数二的高 —— 眼睛却分不清。**
原因：加深把原本的淡黄压成了橄榄/浊金，与浊粉同属低彩度"闷"色调，
与图7 棕 vs 粉是**同一种失效模式**，而 RGB 距离对这类完全无感。

**换位4 而不是位3**：位4 的浊粉本就与 `#8984AB`、`#944195` 同属紫系，是全局最挤的一支，
换掉它同时解决簇内可分度与全局拥挤。

| | 位3 换 cyan | **位4 换 cyan（采用）** |
| :--- | :---: | :---: |
| 距簇内搭档 | 0.212–0.400 | **0.469–0.570** |
| 全局最小色距 | 0.130（无改善） | **0.155** |

cyan 取 **`#17BECF`** —— CLAUDE.md 点名的标准 cyan，且在 `TIER2_STROKES` 池内，**无需扩池**。
更深的 `#008B8B` 作备选，见 `CAND_01b_cyan.pdf`（位3/位4 × 两个 cyan，共 4 版）。

当前默认色：`#8984AB #CC3D1C #C6B500 #17BECF #944195 #8FB585`
（簇内 0.393 / 0.570 / 0.306，全局最小 0.155，对白底 2.10–6.09）。

加深实现（`darken_by_dL()` / `darken_keep_hue()`）都在 **HCL 空间**做，不在 RGB/HSV 里乘系数：

- **色相 H 逐色不动**，脚本里有硬断言（漂移 >2° 直接 `stop`）—— 这才叫"保留配色"；
- 彩度 C 随亮度下降适当提升，并按该 (H, L) 的**色域上限**截断，否则暗下来会发灰发浑。

## 候选图怎么画：只改 1 个组时，别用整图并排

`CAND_06_warm` 初版是两张完整 18 点 PCA 并排，而两版**只差 3 个点**的颜色
（位4，`#CD5B45` vs `#E6820E`，距离 0.167、色相差 17°）——
用户第一反应是「两个 panel 区别在哪里」。**看不出来是呈现方式的错，不是配色的错。**

修法：`zoom_swap()` 只画**差异所在的那一簇**并放大点径，其余 5 色两版相同故不入图。
产物 `CAND_06_warm_zoom.pdf`，用户当场就选出来了。

**通则：候选之间只差 1 个组的颜色时，用「该簇放大」对照，不要用整图并排。**

`#6E7B8B`（图8）与 `#E6820E`（图6 备选）**都不在现有五级色池内**，是为这两处新搜的。

## 四条只能靠眼睛、写不成断言的结论

这一轮最重要的产出其实是这个 —— **数值指标在这四处都失效，而且失效方向不一致**：

0. **低彩度"闷"色调之间，RGB 距离严重高估可分度**（本轮命中两次）：
   图7 棕 `#B87542` vs 浊粉 `#E9A6A1`（0.266）、
   加深后的浊金 `#C6B500` vs 浊粉 `#CC92B1`（**0.411，全套第二高**）——
   两组都被眼睛判为分不清。**只要两个色都是低彩度中间调，距离数字就不可信。**

1. **RGB 距离 ≠ 知觉距离（暗色方向）**：图6 蓝 `#1F78B4` vs 深绿 `#006D2C` 距离 0.315，
   比判"可"的图3（0.266–0.408）还好，全局 min 0.221 更是 8 个方案里最高 —— 但眼睛判它难分辨。
   **两个都是暗色时，RGB 距离系统性高估可分度。**
2. **RGB 距离 ≠ 知觉距离（低饱和方向，反向失真）**：低饱和彩色靠近灰轴，与灰色的 RGB 距离
   必然小（`#6E7B8B` vs `#ABABAB` 仅 0.184），但一个是蓝灰、一个是中性灰，**色相差异眼睛看得出**。
   所以图8 没有机械套 0.20 门槛。
3. **对白底对比度不能只看单色，要看它的簇内搭档**：同一个淡黄 `#FFED6F`（对白底 1.19）
   在图1 里不可用、在图3 里可用 —— 差别在搭档：图1 配 `#FCCDE5`（1.40，也虚），
   图3 配 `#C75C9F`（3.85，够实）。**单个浅色不致命，六个全浅才致命。**

## 方法学教训：缩略 grid 会低估配色

上一轮的对照 grid 里每个 panel 只有单图约一半宽，**系统性低估了所有方案** ——
图1 由「不采用」升到「可分辨但太浅」、图5 由「尚可」升到「好」。

我据此预测图6 在大图下也会改善，**预测错了**：图6 的问题在大图下依旧。
根因是我拿"自己看放大后的裁剪图"当成了"人看真实大图"的代理 ——
裁剪出来只剩 6 个点、标签又大，判别难度被人为降低。**抽查一部分不能代替看整张图。**

**所以本目录一律以单张大图为准，grid 只作索引。**
