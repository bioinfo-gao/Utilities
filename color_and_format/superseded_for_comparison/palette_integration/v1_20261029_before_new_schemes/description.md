
🎨 方案一：暖橘粉 + 冷灰蓝（6 色）
​​颜色构成：​​
- 暖色系：（粉橘）、（桃橘）、#EBD8C4（米橘）
- 冷色系：#C8DDD0（灰绿蓝）、#B2CDD8（青灰）、#D2E8EE（淡蓝）
​​应用示范：​​ PCA 聚类分析、基因表达小提琴图、时间趋势折线图、物种组成堆叠柱状图、相关性气泡图、样本比例环形图。
​​特点：​​ 整体色调柔和、低饱和度，视觉舒适不刺眼。暖冷两组各自形成渐变，既能做单色系渐变图（比如小提琴图的密度渐变），也能做冷暖对比图（处理组 vs 对照组），适配性强。


🎨 方案二：红橙黄绿青蓝（7 色）
​​颜色构成：​​
F76666（红）、FF9799（浅红）、FF7F0F（橙）、EBDA20（黄）、66D28E（绿）、65D1D2（青）、619FD2（蓝）
​​应用示范：​​ 多系列折线图、分组柱状图、散点图（PCA 聚类）、热图、堆叠面积图。
​​特点：​​ 色相覆盖最全，从暖红经黄绿过渡到冷蓝，类似彩虹色但更克制。适合需要区分较多数据系列（7-8 组）或需要连续色标的场景，比如热图和堆叠面积图。
三套方案的选择建议：
- ​​方案一​​：数据系列 4-6 个，需要强对比和视觉冲击力的场景（如期刊封面级图表）。
- ​​方案二​​：偏柔和风格，适合 4-6 个系列，尤其是需要渐变效果的小提琴图、气泡图。

 方案三：暖橙 + 冷蓝（8 色）
​​颜色构成：​​
- 暖色系：（黄橙）、（深橙色）
-冷色系：（浅天蓝）、（浅粉红）、（深红色）、（中蓝色）、（深蓝色）、（灰蓝紫）
​​应用示范：​​ 分组柱状图、折线图、散点气泡图、相关性热图、堆叠柱状图、多组折线图。
​​特点：​​ 色彩饱和度高、对比鲜明，8 个颜色能覆盖多系列图表。暖色适合做主色和强调色，冷色做背景和辅助色，层次感很强。底部还标注了各色的功能定位：主要填充、强调色、辅助色、对比色、重要数据、高亮强调、补充色。
